# RT Shop 3.0 (Forge 1.20.1)

RT1 - 2 모드팩(Forge 1.20.1, 47.4.x)용 독립 모드입니다. 중세풍 NPC 상점과 Gold 경제에 **수표, 상점 씨앗과 작물 별 등급, 물고기 무게 가격, 식품 상인, 토지와 보관함 PIN** 을 더했습니다.

- 다른 모드를 고치지 않습니다 (믹스인 없음). 요리·농사·낚시 모드는 설치되어 있으면 자동으로 연동됩니다.
- 서버와 모든 클라이언트에 같은 jar 가 필요합니다.

## 한눈에 보기

| 기능 | 내용 |
|------|------|
| 화폐 | 가상 화폐 Gold(G). 서버에 저장되는 숫자이며, 화면의 금화 상자에 소지금이 표시됩니다 |
| 사망 손실 | 사망 시 **소지금**의 5~50% 를 무작위로 잃습니다. 예금은 안전합니다 |
| 은행 | 은행 NPC 를 직접 찾아가야 입금·출금할 수 있습니다. 이자는 없습니다 |
| 수표 | `/rtshop check <금액>` 으로 소지금을 실물 수표로 만들어 직접 건넵니다. 받은 사람이 들고 우클릭하면 **소지금**에 들어옵니다 |
| 상인 | 농작물 · 식품 · 수산물 · 장비 · 잡화 · 토지 상인과 은행원 |
| 상점 화면 | 검색, 카테고리, 정렬, 격자/목록, 수량 입력, 전부 판매. 인벤토리가 가득 차면 구매 불가 |
| 농사 | 씨앗은 상점에서 산 것만 심을 수 있고, 수확해도 씨앗이 나오지 않습니다. 수확물에는 1~3별 등급이 붙습니다 |
| 낚시 | Starcatcher 로 낚은 물고기는 무게가 무거울수록 비싸게 팔립니다 |
| 요리 | 음식은 "재료를 상점에서 사서 만드는 비용 + 수고비"에 매입합니다 |
| 토지 | 토지 문서를 사서 원하는 곳에서 사용. 권한 설정, 보관함 PIN, 확장 |

## 2.x 에서 올리는 경우

- **전체 물가가 10배 단위로 바뀌었습니다** (밀 4G → 40G). 설탕·그릇처럼 1G 보다 싼 재료와 별 등급별 가격 차이를 정확히 표현하기 위해서입니다.
  기존 월드의 소지금과 예금은 처음 불러올 때 자동으로 10배가 됩니다 (가치는 그대로).
- 이전 상점 파일(`config/rtshop/shops/*.json`)은 `config/rtshop/backup/` 으로 옮겨지고 새 가격표가 설치됩니다.
- 이미 세워 둔 상인 NPC 는 그대로 쓸 수 있습니다. 식품 상인과 토지 상인만 새로 세우면 됩니다.

## 설치

1. [Releases](../../releases) 의 `rtshop-forge-1.20.1-3.0.0.jar` 를 받아 프로필의 `mods` 폴더에 넣습니다. 이전 버전 jar 는 지웁니다.
2. 서버에도 같은 jar 를 넣습니다.
3. 처음 실행하면 `config/rtshop/` 아래에 설정 파일이 만들어집니다.

## 처음 세팅 (OP)

상인을 세울 자리에 서서 입력합니다. NPC 는 움직이지 않고 죽지 않습니다.

```
/rtshop npc farmer       농작물 상인 (작물 매입, 씨앗·농기구 판매)
/rtshop npc food         식품 상인 (식재료 판매, 음식 매입)
/rtshop npc fisher       수산물 상인
/rtshop npc blacksmith   장비 상인 (무기·방어구·도구, 광물 매입)
/rtshop npc general      잡화 상인
/rtshop npc land         토지 상인
/rtshop npc bank         은행원
```

NPC 를 없애려면 크리에이티브 모드에서 `/kill @e[type=villager,distance=..2]`.

## 플레이어 안내

### Gold, 은행, 수표
- 첫 접속 시 1,000G 를 받습니다. 사망하면 소지금의 5~50% 를 잃으므로 큰돈은 은행에 맡깁니다.
- `/rtshop check 500` : 소지금 500G 가 **Gold 수표** 아이템이 됩니다. 상대에게 던져 주거나 상자에 넣어 전달하고, 받은 사람이 들고 우클릭하면 소지금에 500G 가 들어옵니다.
  수표는 복사하거나 금액을 고쳐도 소용없습니다 (서버 장부로 확인). 수표를 든 채 사망하면 수표 금액도 같은 비율로 줄어듭니다.
- `/rtshop hud` (또는 조작 설정의 단축키) : Gold 표시 상자를 마우스로 끌어 원하는 위치로 옮깁니다. 방향키로 미세 조정, 숨기기도 가능합니다.

### 농사
- 씨앗은 **농작물 상인에게서 산 것만** 심을 수 있습니다. 작물을 수확하면 씨앗은 나오지 않습니다.
- 당근·감자·양파처럼 작물이 곧 씨앗인 것은 상인이 **"당근 (심기 전용)"** 같은 심기 전용 품목을 따로 팝니다. 모양은 같지만, 수확한 당근은 심을 수 없고 심기 전용 당근은 먹을 수 없습니다.
- 다 자란 작물을 우클릭하면 수확됩니다. 인벤토리에 같은 상점 씨앗이 있으면 한 개를 써서 자동으로 다시 심습니다.
  철·금 괭이는 3×3, 다이아몬드 괭이는 5×5, 네더라이트 괭이는 7×7 범위를 한 번에 수확합니다 (웅크리면 한 칸만).
- 상점 씨앗으로 길러 직접 수확한 작물에는 **별 등급**이 붙습니다.

  | 등급 | 확률 | 매입가 |
  |------|------|--------|
  | ★ | 65% | 가격표의 90% |
  | ★★ | 27% | 가격표의 110% |
  | ★★★ | 8% | 가격표의 140% |
  | 등급 없음 (상점에서 산 것 등) | - | 가격표의 50% |

  평균하면 가격표 가격과 같습니다. 작물로 요리를 만들면 등급은 사라지고 음식값은 가격표 기준으로 매겨지므로, 그냥 팔든 요리해서 팔든 평균 수입은 같습니다.

### 낚시
- Starcatcher 로 낚은 물고기는 희귀도로 기준 가격이 정해지고, 무게에 따라 **75%(가장 가벼움) ~ 125%(가장 무거움)** 로 매입합니다. 황금 물고기는 3배입니다.
- 평균 무게의 물고기가 가격표 가격이므로 다른 직업과 평균 수입이 맞춰져 있고, 변동 폭도 ±25% 로 제한됩니다.

### 요리
- 식품 상인은 식재료를 팔고, 조리한 음식을 사 줍니다.
- 음식 매입가 = **재료를 가격표대로 샀을 때의 원가 × (1 + 마진) + 수고비**. 그래서 재료를 사서 만들어 팔면 손해가 나지 않습니다.
- 원가는 **가장 싼 조리법, 가장 싼 재료** 기준입니다. 상점에서 음식에 마우스를 올리면 "매입가 기준 재료"가 표시됩니다. 그 재료대로 만들면 본전 이상입니다.
  같은 음식을 더 비싼 방법으로 만들면 (예: 밀 3개로 빵을 조합하는 대신 반죽을 구우면 밀 1개로 빵 1개) 그만큼 덜 남습니다.
- 화로·조합대처럼 자동화하거나 한꺼번에 찍어 낼 수 있는 조리에는 수고비가 없습니다 (있으면 재료를 사서 굽기만 해도 돈이 불어납니다).
  팬·찜기·주전자·양조통처럼 손이 가는 조리에만 수고비가 붙습니다.
- 우유·물 양동이 값에는 양동이 값이 들어 있습니다. 다 쓴 빈 양동이를 되팔면 그대로 돌려받습니다.

### 토지
- 토지 상인에게서 문서를 삽니다: **첫 토지 문서**(16×16×16, 한 사람당 한 번, 할인) · **토지 문서**(16×16×16) · **대형 토지 문서**(32×32×32).
- 문서를 들면 토지가 될 범위가 입자로 보입니다 (초록 = 가능, 빨강 = 불가). 원하는 곳에서 우클릭하면 내 토지가 됩니다.
- 내 토지 옆에서 쓰면 기존 토지에 붙어 **확장**되고, 떨어진 곳에서 쓰면 **별도의 토지**가 됩니다. 내 토지 안에서 위나 아래를 보고 쓰면 위아래로 확장됩니다.
- 기본 설정은 **주인만** 상호작용 가능합니다. `/rtshop land` (또는 단축키)로 토지 설정을 열어
  전체 또는 플레이어별로 `블록 설치 / 블록 파괴 / 보관함 / 문·레버 사용 / 동물·엔티티` 권한을 언제든 바꿀 수 있습니다.
- **보관함 PIN**: 내 토지의 상자·통 등을 열면 화면 위에 `PIN 설정` 버튼이 나옵니다. 숫자 4~8자리를 정하면
  주인 외에는 PIN 을 입력해야 열 수 있고, 여러 번 틀리면 잠시 잠깁니다. 호퍼로 빼 가는 것과 폭발·피스톤도 막습니다.
- 토지 설정에서 **토지 반환**을 누르면 토지가 풀리고 문서를 돌려받습니다.

## 가격 원칙

1. 원재료(만들 수 없는 것)는 가격표 값에 팔고 그 50% 에 매입합니다 (별·무게가 붙은 수확물은 위 표대로).
2. 만들 수 있는 물건(음식·장비·가공품)은 **재료 원가만큼** 매입하고, 상점 판매가는 그 2배 이상입니다.
   재료를 사서 만들어 팔면 본전 이상이고, 만들어 되파는 것만으로 돈이 불어나지도 않습니다.
3. 요리 재료로 쓰는 가공품(설탕, 기름, 유리병, 그릇 등)은 원가 이하로 팝니다.
4. 자동 농장으로 무한히 쌓이는 것(사탕수수, 수박, 호박, 몹 드롭 등)은 값이 아주 낮고, 대나무·켈프·돌·모래 같은 것은 매입하지 않습니다.

`/rtshop export` 를 실행하면 `config/rtshop/export/` 에 실제 적용된 가격과 점검 결과(`audit.txt`)가 저장됩니다.

## 경제 보호 장치 (`config/rtshop/economy.json`)

| 설정 | 기본값 | 설명 |
|------|--------|------|
| `playerKillOnlyDrops` | 철 골렘, 좀비화 피글린, 가디언 | 플레이어가 직접 잡지 않으면 전리품이 나오지 않습니다. 자동 농장으로 철·금·물고기가 무한히 쌓이는 것을 막습니다. `[]` 로 비우면 바닐라와 같습니다 |
| `villagerTrading` | `filtered` | 주민·떠돌이 상인의 거래 중 "상인 NPC 가 매입하는 물건을 파는 거래"만 사라집니다 (에메랄드로 빵·철 갑옷을 받아 되파는 무한 돈벌이 방지). 인챈트 책이나 에메랄드를 받는 거래는 그대로입니다. `allow` = 바닐라 그대로, `block` = 주민 거래 전체 차단 |

## 설정 파일 (`config/rtshop/`)

| 파일 | 내용 |
|------|------|
| `shops/*.json` | 상점별 품목과 가격. 파일 이름이 상점 ID (`/rtshop npc <ID>`). 새 파일을 만들면 새 상점이 됩니다 |
| `pricing.json` | 재판매 비율, 조리 종류별 마진·수고비, 물고기 무게 배율 |
| `farming.json` | 씨앗 규칙, 별 등급 확률·배율, 괭이 수확 범위 |
| `land.json` | 토지 크기, 한 사람당 최대 개수, PIN 자릿수 등 |
| `economy.json` | 시작 Gold, 사망 손실, 보호 장치 |

수정 후 `/rtshop reload` 로 적용합니다. `farming.json` 은 클라이언트에도 같은 내용을 넣어야 아이템 설명이 맞게 나옵니다.

## 명령어

| 명령어 | 권한 | 설명 |
|--------|------|------|
| `/rtshop balance` | 모두 | 소지금과 예금 확인 |
| `/rtshop check <금액>` | 모두 | 소지금으로 수표 발행 |
| `/rtshop hud` | 모두 | Gold 표시 위치 조정 |
| `/rtshop land` | 모두 | 토지 설정 화면 |
| `/rtshop npc <종류>` | OP | 상인·은행원 NPC 소환 |
| `/rtshop open <상점>` | OP | NPC 없이 상점 열기 (테스트용) |
| `/rtshop gold give\|take\|set\|check <플레이어> [금액]` | OP | Gold 관리 |
| `/rtshop land bypass` | OP | 토지 보호 무시 켜기/끄기 |
| `/rtshop reload` · `/rtshop export` | OP | 설정 다시 읽기 · 가격표 내보내기 |

## 알아 둘 점

- 음식값은 "가장 싼 방법" 기준이라, 여러 재료 중 하나를 고르는 조리법(예: 아무 채소)에 비싼 재료를 쓰면 그만큼 덜 남습니다.
- 가격표에 없는 다른 모드의 재료는 낮은 추정가(기본 2G)로 계산됩니다. 제값을 쳐 주려면 상점 파일에 가격을 적어 주세요 (`audit.txt` 에 목록이 나옵니다).
- 업데이트 전에 심어 둔 작물은 그대로 자라지만 수확물에 별이 붙지 않습니다.
- 가격은 서버 운영 중에 조정해야 하는 값입니다. 기본값은 "생활 직업 1시간 수입 약 20,000G" 를 기준으로 잡았습니다.

## 빌드와 검증

`main` 에 올라가면 GitHub Actions 가 jar 를 빌드하고, 테스트 서버를 띄워 가짜 플레이어로 경제·상점·농사·토지·PIN·가격 규칙을 자동 점검한 뒤 Releases 에 올립니다.
직접 빌드하려면 JDK 17 에서 `./gradlew build` (결과물: `build/libs/`).
