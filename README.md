# RT Shop 3.0 (Forge 1.20.1)

RT1 - 2 모드팩(Forge 1.20.1, 47.4.x)용 독립 모드입니다. 중세풍 NPC 상점과 Gold 경제에 **수표, 상점 씨앗과 작물 별 등급, 물고기 무게 가격, 식품 상인, 토지와 보관함 PIN** 을 더했습니다.

- 다른 모드를 고치지 않습니다 (믹스인 없음). 요리·농사·낚시 모드는 설치되어 있으면 자동으로 연동됩니다.
- 서버와 모든 클라이언트에 같은 jar 가 필요합니다.

## 한눈에 보기

| 기능 | 내용 |
|------|------|
| 화폐 | 가상 화폐 Gold(G). 서버에 저장되는 숫자이며, 화면의 금화 상자에 소지금이 표시됩니다 |
| 사망 손실 | 사망 시 **소지금**의 5~50% 를 무작위로 잃습니다. 예금은 안전합니다 |
| 은행 | 은행 NPC 를 직접 찾아가야 입금·출금할 수 있습니다. 이자는 없습니다 |
| 수표 | `/rtshop check <금액>` 으로 소지금을 실물 수표로 만들어 직접 건넵니다. 받은 사람이 들고 우클릭하면 **소지금**에 들어옵니다 |
| 상인 | 농작물 · 식품 · 수산물 · 장비 · 잡화 · 토지 상인과 은행원 |
| 상점 화면 | 검색, 카테고리, 정렬, 격자/목록, 수량 입력, 전부 판매. 인벤토리가 가득 차면 구매 불가 |
| 농사 | 씨앗은 상점에서 산 것만 심을 수 있고, 수확해도 씨앗이 나오지 않습니다. 수확물에는 1~3별 등급이 붙습니다 |
| 낚시 | Starcatcher 로 낚은 물고기는 무게가 무거울수록 비싸게 팔립니다 |
| 요리 | 음식은 "재료를 상점에서 사서 만드는 비용 + 수고비"에 매입합니다 |
| 토지 | 토지 문서를 사서 원하는 곳에서 사용. 권한 설정, 보관함 PIN, 확장 |
| 구획 (3.9) | OP 가 구불구불한 밭 모양을 칸 단위로 그대로 골라 판매. 플레이어는 그 자리에서 구매·반환 |
| 토지 상인 창 (3.14) | 토지 상인의 **[구획 토지 ▶]** 에서 확대·이동되는 지도로 토지·구획·초보 농지를 보고 삼 (상인에게서만 구매) |
| 성 안 토지 (3.14) | 아모노스 맵의 성 안 네모 토지 26칸. 사면 평지가 되고 경계에 걸친 나무·건물은 통째로 제거. 성 영역 전체 보호·몬스터 스폰 금지 |
| 장비 강화 (3.13) | 강화 모루에서 무기·방어구를 +11 까지 강화. Mining Master 보석 + Spelunkery 광물 + Gold. 결과는 성공·유지·손상·파괴 |

## 2.x 에서 올리는 경우

- **전체 물가가 10배 단위로 바뀌었습니다** (밀 4G → 40G). 설탕·그릇처럼 1G 보다 싼 재료와 별 등급별 가격 차이를 정확히 표현하기 위해서입니다.
  기존 월드의 소지금과 예금은 처음 불러올 때 자동으로 10배가 됩니다 (가치는 그대로).
- 이전 상점 파일(`config/rtshop/shops/*.json`)은 `config/rtshop/backup/` 으로 옮겨지고 새 가격표가 설치됩니다.
- 이미 세워 둔 상인 NPC 는 그대로 쓸 수 있습니다. 식품 상인과 토지 상인만 새로 세우면 됩니다.

## 설치

1. [Releases](../../releases) 의 `rtshop-forge-1.20.1-3.0.0.jar` 를 받아 프로필의 `mods` 폴더에 넣습니다. 이전 버전 jar 는 지웁니다.
2. 서버에도 같은 jar 를 넣습니다.
3. 처음 실행하면 `config/rtshop/` 아래에 설정 파일이 만들어집니다.

## 처음 세팅 (OP)

상인을 세울 자리에 서서 입력합니다. NPC 는 움직이지 않고 죽지 않습니다.

```
/rtshop npc farmer       농작물 상인 (작물 매입, 씨앗·농기구 판매)
/rtshop npc food         식품 상인 (식재료 판매, 음식 매입)
/rtshop npc fisher       수산물 상인
/rtshop npc blacksmith   장비 상인 (무기·방어구·도구, 광물 매입)
/rtshop npc general      잡화 상인
/rtshop npc land         토지 상인
/rtshop npc bank         은행원
/rtshop npc quest_guide  모험 안내인 (튜토리얼 퀘스트)
/rtshop npc job          직업 안내인
/rtshop npc attendance   출석 NPC (시청 서기 하루) — 시청에 두세요
/rtshop npc gacha        뽑기 상인 (행운 상인 럭키)
```

NPC 를 없애려면 크리에이티브 모드에서 `/kill @e[type=villager,distance=..2]`.

## 플레이어 안내

### Gold, 은행, 수표
- 첫 접속 시 1,000G 를 받습니다. 사망하면 소지금의 5~50% 를 잃으므로 큰돈은 은행에 맡깁니다.
- `/rtshop check 500` : 소지금 500G 가 **Gold 수표** 아이템이 됩니다. 상대에게 던져 주거나 상자에 넣어 전달하고, 받은 사람이 들고 우클릭하면 소지금에 500G 가 들어옵니다.
  수표는 복사하거나 금액을 고쳐도 소용없습니다 (서버 장부로 확인). 수표를 든 채 사망하면 수표 금액도 같은 비율로 줄어듭니다.
- `/rtshop hud` (또는 조작 설정의 단축키) : Gold 표시 상자와 **퀘스트 HUD**(3.6.3)를 마우스로 끌어 원하는 위치로 옮깁니다. HUD 를 눌러 고른 뒤 크기(휠·작게/크게), 퀘스트 HUD 의 너비(좁게/넓게)와 한 번에 보일 퀘스트 수(1~5, 목록에서 선택)를 바꾸고, 각각 켜고 끌 수 있습니다. Tab 으로 다른 HUD 를 고르고 방향키로 미세 조정합니다. **글꼴 ▼**(게임 기본 글꼴, 유니폰트, 리소스팩·모드가 가진 글꼴)과 **글자 크기 ▼**(퍼센트)도 HUD 마다 따로 고를 수 있습니다 (3.6.4).
- **퀘스트 HUD**: 진행 중인 퀘스트를 받은 순서대로 보여 줍니다. 목표마다 진행도(예: 좀비 처치 5/12)가 실시간으로 바뀌고, 다 채우면 "→ ○○ 에게 돌아가기" 가 초록색으로 나옵니다. 설정은 `config/rtshop/client.json` 의 questHud* 값에 저장됩니다.

### 농사
- 씨앗은 **농작물 상인에게서 산 것만** 심을 수 있습니다. 작물을 수확하면 씨앗은 나오지 않습니다.
- 당근·감자·양파처럼 작물이 곧 씨앗인 것은 상인이 **"당근 (심기 전용)"** 같은 심기 전용 품목을 따로 팝니다. 모양은 같지만, 수확한 당근은 심을 수 없고 심기 전용 당근은 먹을 수 없습니다.
- 가격표에 없는 다른 모드의 씨앗도 상인이 자동으로 팝니다 (씨앗 20G, 작물 겸 씨앗은 작물 가격의 2.5배. `farming.json` 의 `autoListMissingSeeds`).
- 다 자란 작물을 우클릭하면 수확됩니다. 인벤토리에 같은 상점 씨앗이 있으면 한 개를 써서 자동으로 다시 심습니다.
  철·금 괭이는 3×3, 다이아몬드 괭이는 5×5, 네더라이트 괭이는 7×7 범위를 한 번에 수확합니다 (웅크리면 한 칸만).
- 상점 씨앗으로 길러 직접 수확한 작물에는 **별 등급**이 붙습니다.

  | 등급 | 확률 | 매입가 |
  |------|------|--------|
  | ★ | 65% | 가격표의 90% |
  | ★★ | 27% | 가격표의 110% |
  | ★★★ | 8% | 가격표의 140% |
  | 등급 없음 (상점에서 산 것 등) | - | 가격표의 50% |

  평균하면 가격표 가격과 같습니다. 작물로 요리를 만들면 등급은 사라지고 음식값은 가격표 기준으로 매겨지므로, 그냥 팔든 요리해서 팔든 평균 수입은 같습니다.

### 낚시
- Starcatcher 로 낚은 물고기는 희귀도로 기준 가격이 정해지고, 무게에 따라 **75%(가장 가벼움) ~ 125%(가장 무거움)** 로 매입합니다. 황금 물고기는 3배입니다.
- 평균 무게의 물고기가 가격표 가격이므로 다른 직업과 평균 수입이 맞춰져 있고, 변동 폭도 ±25% 로 제한됩니다.

### 요리
- 식품 상인은 식재료를 팔고, 조리한 음식을 사 줍니다.
- **식당 주인 (3.20, `/rtshop npc restaurant`)**
  - **요리사 직업을 가진 플레이어만** 식당 주인에게 요리를 팔 수 있습니다. 식품 상인에게 팔 때보다 **5% 더** 받고, 이 5% 는 요리사 패시브(손으로 만든 요리 +28%)와 **따로 곱해집니다** (예: 100 G 짜리 요리 → 식품 상인 128 G, 식당 134 G).
  - 식당은 **처음에는 아무것도 팔지 않습니다.** 요리사가 한 번이라도 판 요리가 도감처럼 하나씩 메뉴에 올라가고(서버 전체에 알림), 메뉴에 오른 요리는 **직업과 상관없이 누구나** 살 수 있습니다. 창 제목 옆에 "메뉴 3/57" 처럼 진행도가 보이고, 창을 열어 둔 사람에게도 새 메뉴가 바로 나타납니다.
  - 다루는 요리와 가격은 식품 상인의 '요리'·'음료·주류' 구분 그대로입니다. 식당에서 사서 식당에 되팔아 남는 일이 없도록 판매가는 항상 (보너스 포함 매입가 × 요리사 보너스)보다 비쌉니다.
  - 설정 `config/rtshop/restaurant.json`: `bonus`(0.05), `sellJob`(cook), `priceMultiplier`, `announce`, `sourceSellsDishes`(false 로 바꾸면 식품 상인은 요리를 사 주기만 하고 팔지 않음 → 요리는 식당에서만 구매).
  - OP: `/rtshop restaurant status` · `unlock <아이템>` · `unlock all` · `lock <아이템>` · `reset`.
- **손으로 만드는 요리는 재료를 모두 상점에서 사서 만들어도 재료비의 110% 이상**을 받고, **요리사는 140% 이상**을 받습니다 (3.5). 화로·훈연기에 상점 재료를 바로 넣어 만들 수 있는 음식은 자동화로 돈이 불어나지 않게 본전이고 요리사 보너스도 없습니다.
- **재료를 모두 상점에서 사서 어떤 조리법으로 만들어 팔아도 손해가 나지 않습니다.** 음식마다 재료를 살 수 있는 모든 조리법의 재료비를 계산하고, 그중 가장 비싼 것 이상으로 사 줍니다 (3.3).
- 그 위에 손이 가는 조리법에는 마진·수고비가 붙습니다: 매입가 = 가장 싼 방법의 원가 × (1 + 마진) + 수고비, 단 위 하한보다 낮아지지 않음.
- 요리 재료인데 어느 상점에서도 팔지 않던 식재료(모드 재료 등)는 식품 상인에 자동으로 올라갑니다. 서버 로그와 `/rtshop export` 의 `audit.txt` 에 목록이 나옵니다.
- 상점에서 음식에 마우스를 올리면 "매입가 기준 재료"가 표시됩니다.
- 같은 음식을 싼 조리법으로 만들면 그 차이만큼 더 남습니다. 차이가 큰 음식은 `audit.txt` 의 "재료비 차이가 큰 경우"에 나옵니다.
- 끄려면 `pricing.json` 의 `purchaseFloor`, `autoListFoodIngredients` 를 false 로.
- 화로·조합대처럼 자동화하거나 한꺼번에 찍어 낼 수 있는 조리에는 수고비가 없습니다 (있으면 재료를 사서 굽기만 해도 돈이 불어납니다).
  팬·찜기·주전자·양조통처럼 손이 가는 조리에만 수고비가 붙습니다.
- 우유·물 양동이 값에는 양동이 값이 들어 있습니다. 다 쓴 빈 양동이를 되팔면 그대로 돌려받습니다.

### 토지
- 토지 상인에게서 문서를 삽니다: **첫 토지 문서**(16×16, 한 사람당 한 번, 할인) · **토지 문서**(16×16) · **대형 토지 문서**(32×32).
- 토지는 **발밑 4칸(대형 8칸) 아래부터 월드 꼭대기까지** 덮습니다 (3.3). 예전에 만든 토지도 서버를 켜면 위쪽만 꼭대기까지 늘어납니다 (위에 다른 사람 토지가 있으면 그 바로 아래까지).
- 문서를 들면 토지가 될 범위가 입자로 보입니다 (초록 = 가능, 빨강 = 불가). 원하는 곳에서 우클릭하면 내 토지가 됩니다.
- 내 토지 옆에서 쓰면 기존 토지에 붙어 **확장**되고, 떨어진 곳에서 쓰면 **별도의 토지**가 됩니다. 내 토지 안에서 아래를 보고 쓰면 땅속으로 16칸(대형 32칸) 더 확장됩니다.
- 기본 설정은 **주인만** 상호작용 가능합니다. `/rtshop land` (또는 단축키)로 토지 설정을 열어
  전체 또는 플레이어별로 `블록 설치 / 블록 파괴 / 보관함 / 문·레버 사용 / 동물·엔티티` 권한을 언제든 바꿀 수 있습니다.
- **보관함 PIN**: 내 토지의 상자·통 등을 열면 화면 위에 `PIN 설정` 버튼이 나옵니다. 숫자 4~8자리를 정하면
  주인 외에는 PIN 을 입력해야 열 수 있고, 여러 번 틀리면 잠시 잠깁니다. 호퍼로 빼 가는 것과 폭발·피스톤도 막습니다.
- 토지 설정에서 **토지 반환**을 누르면 토지가 풀리고 문서를 돌려받습니다.

### 구획 — 모양이 불규칙한 토지 (3.9)

밭처럼 직선이 거의 없는 땅은 16×16 문서로는 정확히 나눌 수 없어서, **OP 가 칸(블록 기둥) 단위로 모양을 골라 등록**합니다.
구획은 일반 토지와 똑같이 보호되고(땅속 `plotDepthBelow` 칸부터 하늘 끝까지), 산 사람은 권한 설정·보관함 PIN 을 그대로 씁니다.

**OP: 구획 만들기**

1. `/rtshop plot wand` 로 **구획 지팡이**를 받습니다. 들고 있으면 고른 칸이 노란 입자, 이미 있는 구획이 흰(판매 중)·하늘색(주인 있음) 입자로 보입니다.
2. 웅크리고 우클릭할 때마다 모드가 바뀝니다. 우클릭은 멀리(128칸) 있는 땅도 가리키면 됩니다. 좌클릭은 각 모드의 반대 동작입니다.

   | 모드 | 우클릭 |
   |------|--------|
   | **밭 채우기** | 밭을 한 번 누르면 작물·꽃·흙으로 이어진 밭 하나를 **모양 그대로** 고릅니다. 가운데 나무·물길은 메우고, 둘레의 풀 테두리 한 줄까지 넣되 길·물·다른 토지는 넘지 않습니다 |
   | 밭 빼기 | 누른 밭 하나를 선택에서 뺍니다 |

### 토지 상인 창과 성 안 토지 (3.14)

토지 상인 상점 창의 위쪽 **[구획 토지 ▶]** 를 누르면 구획 토지 창이 열립니다. **토지·구획·농지는 토지 상인에게서만 살 수 있습니다** (명령어 구매 없음). 창 왼쪽 위 **[◀ 토지 상점]** 으로 문서 상점으로 돌아갑니다.

- **지도**: 끌어서 이동, 휠·+/- 로 확대·축소, ⌖ 로 고른 토지로 돌아오기. 성 근처는 성 전체 지도, 다른 곳은 그 둘레를 서버가 그려 보냅니다. 고른 토지는 노란 테두리, 판매 중은 흰색, 내 토지는 초록, 팔린 토지는 회색, 내 위치는 흰 점.
- **지금 모습 / 구매 후**: 고른 토지 둘레를 위에서 본 지도. 빨간 빗금은 사면 함께 없어지는 나무·건물의 바깥쪽 부분입니다.
- **성 안 토지 (아모노스 맵, 3.20 새 배치)**: 성 안 네 구역을 **빈틈 없이** 25칸으로 나눴습니다. 토지 사이의 경계는 가로·세로 직선이고 바깥쪽만 길·성벽을 따라갑니다. 칸마다 229~285블록(약 256)이며, 토지끼리 맞닿아 있습니다 (사이 간격 없음). 길·성벽·물은 들어가지 않습니다.
  - 이름은 구역 글자 + 순서입니다: **A**(북서, 5칸) · **B**(북동, 6칸 — 남쪽 정원의 흙길 포함) · **C**(남서, 7칸) · **D**(남, 7칸) → "성 안 토지 A-1" … "D-7". 지도에는 A1, C4 처럼 표시되고, 실제 칸 모양대로 그려집니다. 값은 블록 수에 비례합니다.
  - 북쪽의 두 건물(지도에 흰 원으로 표시해 주신 곳)과, 구역 밖으로 절반 넘게 걸친 건물은 토지에 들어가지 않고 토지를 살 때 함께 철거되지도 않습니다.
  - **예전 배치(1~34번)는 없어집니다.** 서버를 켤 때 한 번, 주인이 없는 예전 토지는 지워지고(샀다가 돌려줘서 평지가 된 칸은 처음 모습으로 되돌린 뒤 지움) 새 25칸이 등록됩니다. **이미 누가 산 예전 토지는 그대로 남습니다** (그 자리와 칸이 겹치는 새 토지는 등록되지 않음).
  - 사면 토지 안을 평평한 풀밭으로 만들고, **경계에 걸친 나무·건물은 잘린 채 남지 않게 통째로 없앱니다**. 남의 토지 부분은 절대 건드리지 않습니다.
  - 높이 범위는 일반 토지 문서와 같습니다 (지면 아래 `depthBelowFeet` 칸 ~ 하늘 끝).
  - 바꾸기 전 모습은 `world/rtshop/castle_backup/` 에 저장되고 OP 는 `/rtshop plot castle restore <번호>` 로 되돌릴 수 있습니다.
- **성 영역 보호**: 북쪽 강·동쪽 바다·서쪽 강과 호수로 둘러싸인 성과 농경지 전체. 산 토지 밖에서는 블록 부수기·놓기·상자 등 상호작용이 막히고(문·다락문·울타리 문·버튼은 누구나 쓸 수 있음), 몬스터가 생기지 않습니다 (상인 NPC 와는 거래 가능). 산 토지 안에서는 주인과 권한을 받은 사람만 쓸 수 있습니다. 끄기: `land.json` 의 `castleZoneProtect`.
- **농경지를 사면 치워집니다 (3.20.1)**: 구획 토지(농경지)를 사면 성 안 토지처럼 그 토지 칸 안의 **작물·구조물(울타리·허수아비·나무 등 땅 위의 것)** 이 치워집니다. 경작지·흙·물길은 그대로 남아 바로 심을 수 있고, 토지 밖은 건드리지 않습니다. 치운 블록은 `world/rtshop/plot_backup/` 에 저장됩니다. 끄기: `land.json` 의 `plotClearOnBuy`.
- **경계 표시 (3.19)**: 토지·농경지에 들어갔다고 저절로 뜨지 않습니다. 토지 안에서 **`/border`** (= `/rtshop border`, `on`/`off` 도 가능) 를 치면 지금 서 있는 토지의 둘레가 보이고, 다시 치면 꺼집니다. 테두리는 땅을 따라가는 낮은 선 두 줄(바닥·한 칸 위)과 모서리의 짧은 기둥입니다 (예전처럼 하늘까지 솟는 격자 벽이 아니라서, 위를 봐도 화면 가운데에 잔상이 뜨지 않습니다). 토지 문서를 들고 있을 때의 후보 표시와 토지 창의 [경계 보기](20초)는 그대로입니다.
- **토지 상인 지도 (3.19)**: 지금 보고 있는 갈래(성 안 토지 / 구획 토지 / 초보 농지)의 토지만 그립니다 (다른 갈래와 겹쳐 보이지 않음). 농경지처럼 네모가 아닌 토지는 실제 모양대로 그려지고, 마우스로 고를 때도 실제 모양을 따릅니다.
- 설치: 아모노스 맵이면 서버를 켤 때 자동 (예전 배치는 안 팔린 칸만 새 배치로 바뀜). 직접: `/rtshop plot castle install` · `status` · `remove`.

### PvP 켜기/끄기 (3.20)

- **마을(성 영역)에서는 누구도 PvP 를 할 수 없습니다** (강제, 끌 수 없음). 그 밖에서는 기본이 **PvP 불가**이고, OP 가 정한 **PvP 가능 구역** 안에서만 PvP 를 켤 수 있습니다. OP 가 `/rtshop pvp outside on` 을 하면 마을 밖 어디서나 켤 수 있게 됩니다.
- 플레이어는 **`/pvp`**(누를 때마다 켜짐↔꺼짐), `/pvp on`, `/pvp off`, `/pvp status` 또는 **조작 설정 → RT Shop → "PvP 켜기/끄기" 키**(기본 지정 안 됨)로 바꿉니다. PvP 가능한 곳이 아니면 `/pvp on` 은 실행되지 않고 이유를 알려 줍니다.
- **때리는 쪽과 맞는 쪽이 모두 PvP 를 켜고 있어야** 피해가 들어갑니다 (근접·화살·마법·길들인 동물 모두). 한쪽이라도 꺼져 있거나 안전 구역이면 피해가 0 이고, 때린 사람 화면에 이유가 뜹니다.
- PvP 가능한 곳을 벗어나거나 마을에 들어오면 **저절로 꺼집니다**. PvP 로 때리거나 맞은 뒤 10초(`combatSeconds`) 동안은 끌 수 없습니다 (도망치며 끄기 방지).
- **PvP 표시(HUD)**: 켜짐(붉은 칼, "PvP ON") / 꺼짐(방패, "PvP OFF")과 지금 있는 곳(안전 구역 · PvP 가능 구역 · PvP 불가 지역)을 보여 줍니다. `/rtshop hud` 에서 Gold·퀘스트 표시처럼 위치·크기·글꼴·글자 크기·숨김을 바꿉니다 (Tab 으로 세 HUD 를 차례로 고름).
- **OP 설정** (`config/rtshop/pvp.json` 에 저장):
  - `/rtshop pvp` 상태 보기 · `/rtshop pvp outside on|off` 마을 밖 PvP 허용/불가
  - 구역 만들기: 한쪽 모서리에서 `/rtshop pvp pos1`, 반대쪽 모서리에서 `/rtshop pvp pos2`, 그다음 `/rtshop pvp zone add <이름>` (안전 구역으로 만들려면 끝에 `safe`). 또는 서 있는 곳 둘레로 `/rtshop pvp zone here <이름> <반경>`.
  - `/rtshop pvp zone list` · `zone remove <이름>` · `zone show`(구역 경계 표시: 빨강 = PvP 가능, 초록 = 안전)
  - `/rtshop pvp combat <초>` 전투 잠금 시간 · `/rtshop pvp set <플레이어> on|off` 강제로 바꾸기 · `/rtshop pvp enable|disable` 시스템 전체 켜기/끄기
  - `server.properties` 의 `pvp=false` 여도 이 시스템이 동작하도록 서버 PvP 는 자동으로 켜집니다 (`manageServerPvp`).

### 주간 레이드 (3.21)

- **준비 (OP)**: `/rtshop npc raid` (레이드 상인: 참가 티켓 판매, 값은 `shops/raid.json`) · `/rtshop npc raid_guide` (레이드 안내인: 포탈 앞에 세워 두세요). 레이드 구역은 처음 입장할 때 자동으로 지어집니다 (기본 위치: 오버월드 20000, 200, 20000 의 공중). 원하는 곳에 두려면 그 자리에서 `/rtshop raid arena here`, 끝나고 돌아올 곳은 `/rtshop raid return here` (정하지 않으면 월드 스폰).
- **입장**: 안내인에게 말을 걸면 짧은 대화 → 이그니스 테마의 입장 화면(조건·보상 목록) → [레이드 입장] → "정말 입장하시겠습니까?" 확인 → 참가 티켓 1장을 쓰고 구역으로 이동합니다. 조건: **일반 이그니스를 1번 이상 처치** (죽인 사람과 근처 40칸 안의 사람이 함께 인정됨).
- **구역 안**: 들어가면 **레이드 소환의 눈**과 **레이드 탈출권**을 받습니다. 가운데 **제단**에 소환의 눈을 쓰면 레이드 이그니스가 깨어나고, 그 뒤로는 다른 사람이 들어올 수 없습니다 (깨어나기 전에는 누구나 입장 가능). 구역 안에서는 블록을 놓거나 부술 수 없고(보스도 못 부숨) PvP 도 안 됩니다.

- **보상** (매주 월요일 오전 6시 초기화, 서버 컴퓨터 시간 기준):

### 장비 강화 (3.13)

**강화 모루**(장비 상인, 8,000G)를 놓고 우클릭합니다. Cinematic Interactions 가 있으면 모루 장면(망치질)이 그대로 재생되고, 없으면 강화 창이 열립니다.

- 왼쪽 칸에 무기나 방어구를 놓으면 결과 칸에 +1 미리보기가 나옵니다. 결과를 꺼내면(망치질) 재료와 Gold 를 쓰고 결과가 정해집니다. 장비에 마우스를 올려도 확률 창은 뜨지 않습니다 (확률·재료는 옆의 **강화 정보 창**에).
- **강화 정보 창 (3.19)**: 장비 이름·단계, **능력치(지금 → 다음: 보너스 %, 실제 공격 피해 / 방어력 / 방어 강도)**, 확률, 재료, Gold, 보호 상태를 한 창에 보여 줍니다. 창 아래 **[상세]** 를 누르면 장비 설명 전체(예전에 마우스를 올리면 뜨던 내용)가 창 안에 나오고 휠로 넘길 수 있습니다. 그래서 장비·결과 칸에 마우스를 올려도 설명 창은 뜨지 않습니다 (Cinematic 모루 장면 포함).
- **강화 정보 창 설정**: 창 아래 [⚙] → 끌어서 위치 옮기기 · 크기(60~150%) · 보이기/숨기기 · 기본값. 숨기면 작은 [강화 정보] 단추만 남습니다.

  - **+9 ~ +10 「각인」(약 4.2초)**: 마법진이 그려지고 여섯 봉인이 하나씩 켜진 뒤, 마법진이 장비 속으로 빨려 들어가고 완전한 어둠. 성공하면 빛기둥과 수정 조각, 실패하면 마법진이 깨져 흩어집니다.
  - **+11 「초월」(약 8.2초)**: 화면이 닫히고 어둠 속에서 열 개의 별이 차례로 켜집니다. 열한 번째 별은 세 번이나 꺼지고, 장비에 금이 가며 모든 것이 한 점으로 무너진 뒤 긴 정적. 성공하면 새벽빛·무지개 고리·세 번의 충격파와 함께 "+11 최고 단계 달성!", 파괴면 장비가 조각나 흩어집니다. 성공하면 **다른 모든 플레이어의 화면 위쪽에도 알림 띠**가 뜹니다.

### 플레이어 상점 (3.16)
- 잡화점에서 **플레이어 상점 진열대**(5,000G)를 사서 놓으면 놓은 사람이 주인입니다. 주인만 부술 수 있고, 부수면 남은 재고가 떨어집니다.
- 주인이 우클릭: **[+ 가방에서 올리기]** 에서 물건을 고르고 개당 가격 · 수량을 정해 올립니다. 오른쪽에 그 물건을 파는 **NPC 상점과 가격(판매가 · 매입가)**, 내 가격이 NPC 판매가보다 몇 % 싼지/비싼지가 나옵니다.
- **[진열대]** 탭에서 가격 변경 · 채우기 · 꺼내기 · 진열 내리기, 상점 이름 바꾸기. 진열은 최대 27 품목, 품목당 9,999개.
- 손님이 우클릭: 품목 · 가격 · 재고를 보고 수량을 정해 지갑의 Gold 로 삽니다 (남의 토지 위 상점도 열 수 있음). 판 돈은 주인이 접속하지 않아도 **주인의 예금**으로 들어갑니다.
- **직원 (3.18)**: 진열대를 놓으면 그 뒤(자리가 없으면 옆·앞·위)에 **직원**이 섭니다. 직원을 우클릭해도 진열대와 똑같은 화면이 열립니다. 직원 이름은 서버 전체에서 겹치지 않게 정해지고(예: "민준 · Dev 의 직원"), 진열대를 부수면 직원도 떠납니다. 직원이 사라져도 잠시 뒤 다시 섭니다.
- **고용비**: 출석이 초기화되는 시각(`attendance.json` 의 기준 시각)마다 직원 1명당 **1,000G** 를 주인의 예금 → 지갑 순으로 냅니다 (`economy.json` 의 `employeeWage`). 낸 내역은 주인에게 알림(접속하지 않았으면 다음 접속 때). 모자라면 그날은 직원이 쉬어 손님이 살 수 없고, 주인이 진열대 화면의 **[고용비 내기]** 를 누르면 바로 다시 일합니다. 고용한 첫날은 무료.

### 조합법·전리품 설정 (3.17, OP)

**조합법** — `/rtshop recipes`
- 아이템 이름이나 조합법 ID 로 찾아서 **[막기]** 를 누르면 그 조합법 하나가, **[아이템]** 을 누르면 그 아이템을 만드는 조합법이 모두 막힙니다. 막힌 조합법은 조합대뿐 아니라 JEI 같은 조합법 보기에서도 사라집니다.
- **[+ 새 조합법]**: 3×3 칸에 재료를 고르고(우클릭 = 비우기) 결과 아이템·개수를 정합니다. '모양 그대로 / 모양 상관없음'. "원래 조합법은 막기" 를 켜 두면 기존 조합법 대신 새 조합법만 쓰입니다 (= 조합법 조절).
- [저장] 하면 바로 서버 전체에 적용됩니다. 파일: `config/rtshop/recipes.json` (`disabled` 에 `mod:모드ID` 를 넣으면 그 모드의 조합법을 통째로 막을 수도 있음, `custom` 에는 데이터팩 형식이면 화로 등 다른 종류도 넣을 수 있음).

**전리품** — `/rtshop loot`
- 왼쪽에서 상자 전리품표(던전, 사막 피라미드, 모드 구조물 상자 등)를 고르면, 서버가 그 상자를 400번 열어 본 **실제 확률**(아이템별 상자 하나당 나올 확률·개수)이 나옵니다. '적용 후' 는 규칙까지 적용된 확률입니다.
- 아이템마다 **[기본] → [끔] → [직접]**: '직접' 이면 확률(%)과 개수(최소~최대)를 정합니다. **[+ 아이템 넣기]** 로 원래 없던 아이템도 넣고, **[원래 전리품 전부 지움]** 으로 새로 짤 수도 있습니다.
- 새로 생기는 상자(아직 열지 않은 상자)부터 적용됩니다. 파일: `config/rtshop/loot.json` — 키를 `minecraft:chests/*` 처럼 `*` 로 끝내면 그 묶음 전체에 적용됩니다.

### 직업

- **전투 직업 1개 + 생활 직업 1개**를 고릅니다. 고르는 즉시 특성이 적용됩니다 (레벨 없음).
- **직업 안내인** NPC(`/rtshop npc job`)에게 말을 걸어 고르고 바꿉니다. `/rtshop job` 이나 "직업 화면 열기" 단축키로는 보기만 할 수 있습니다.
- 처음 고르는 직업은 무료. 바꿀 때는 **전투 8,000 G / 생활 5,000 G** 를 내고 바로 바뀌며, 바꾼 뒤 **전투 48시간 / 생활 24시간** 동안 그 칸을 다시 바꿀 수 없습니다 (실제 시간).
- **전투 직업의 무기 상성 (3.5)**: 직업마다 무기 종류(검·도끼·둔기·창·단검·주먹·활·석궁·총·지팡이·주문)별로 피해와 공격 속도가 오르거나 내려갑니다. 자기 분야 무기는 강하고, 아닌 무기는 서툽니다. 전투 직업이 없으면 상성도 없습니다.
- 탱커는 방패로 근접 공격을 막으면 공격자를 밀쳐 내고 막은 피해의 5%를 되돌려 줍니다. 궁수는 멀리서 맞힐수록 투사체 피해가 늘어 32칸 이상에서 +15% 입니다 (3.5.1).
- 모드 무기(RPG 시리즈, Epic Fight, Cataclysm, TaCZ 총, Iron's Spells·Wizards 지팡이 등)는 이름과 종류로 자동 분류됩니다.
- **직업 편집기 (OP, `/rtshop job edit`)**: 직업별 특성 수치와 무기 상성을 [-][+] 로 바꾸고 저장하면 바로 모든 플레이어에게 적용됩니다. "무기 분류"에서는 손에 든 무기나 목록에서 고른 아이템의 종류를 직접 정할 수 있습니다 (자동 분류가 틀렸을 때).
- **직업별 선행 퀘스트 (3.6)**: 모든 직업은 7단계 선행 퀘스트를 끝내야 고를 수 있습니다. 1단계는 직업 안내인에게서 받고, 2~7단계는 그 직업의 스승에게서 받습니다. 퀘스트 속에서 그 직업에 맞는 모드(Epic Fight, Iron's Spells, Wizards, Rogues & Warriors, Paladins, Archers, Farmer's Delight, Hands-On Delight, Kaleidoscope Cookery, Starcatcher) 사용법을 짧게 알려 주고, 모드가 있으면 모드 무기·도구를 쓰는 목표와 보상으로 바뀝니다 (모드가 없으면 바닐라 목표).
  - 전투 직업 스승(새 NPC, OP 가 세워야 함): `/rtshop npc quest_sword_master`(검술 교관 레온) · `quest_war_chief`(전사 대장 브론) · `quest_shield_keeper`(방패 수호자 가렌) · `quest_hunter`(사냥꾼 리아) · `quest_archmage`(대마법사 엘리스)
  - 생활 직업 스승은 기존 상인: 농부 → 농작물 상인, 어부 → 수산물 상인, 광부 → 장비 상인, 요리사 → 식품 상인
  - 상인·은행원·직업 안내인처럼 원래 화면이 있는 NPC 는 **웅크리고(Shift) 말을 걸면 퀘스트 창**이 열립니다. 받을 퀘스트가 있으면 말을 걸 때 채팅에 [퀘스트 보기] 링크도 나옵니다.
  - 퀘스트를 맡은 상인(농부·어부·요리·대장장이 등)의 상점 화면 제목 옆에는 **[퀘스트] 단추가 항상** 보입니다. 지금 받을 퀘스트가 없으면 숫자 없이 나오고, 눌러 보면 다음 퀘스트를 받으려면 무엇을 먼저 끝내야 하는지 알려 줍니다. 그렇게 연 퀘스트 창의 왼쪽 위 **[◀ 돌아가기]** 를 누르면 그 상인의 상점 화면으로 돌아갑니다 (3.19).
  - 퀘스트 내용은 퀘스트 편집기(`/rtshop quest edit`)에서 고칠 수 있습니다 (`job_quests.json`). 이미 직업을 가진 플레이어는 그대로 유지됩니다.
- 직업의 `unlockFlag`(기본 `unlock_job_<직업ID>`)를 보상으로 주는 퀘스트가 그 직업의 선행 퀘스트입니다.
- 판매 보너스(어부 수산물, 요리사 요리)는 판매 결과 금액에 반영됩니다.
- OP: `/rtshop job set <플레이어> <직업>` · `/rtshop job clear <플레이어>` · `/rtshop job cooldown <플레이어>`

### 퀘스트

- 퀘스트 NPC(머리 위 이름)에게 말을 걸면 퀘스트 창이 열립니다. 왼쪽에서 퀘스트를 고르고 **수락**, 목표를 채운 뒤 다시 찾아가 **완료하기**를 누릅니다.
- 진행 중인 퀘스트는 `/rtshop quest` 또는 조작 설정의 "퀘스트 수첩 열기" 단축키로 볼 수 있습니다 (기본 키 없음).
- 목표 종류: 아이템 납품, 몬스터 처치, 장소 방문, NPC 와 대화, Gold 지불. 납품 아이템과 Gold 는 완료할 때 가져갑니다.
- 동시에 10개까지 진행할 수 있고, 포기한 퀘스트는 다시 받을 수 있습니다.
- 기본으로 "초보 모험가의 길" 4단계(은행 → 첫 수확 → 첫 사냥 → 토지 상인)가 들어 있습니다. 마지막 단계의 선택지는 이후 직업·숨겨진 퀘스트 조건(표식)으로 쓰입니다.

### 출석 (3.7)

- 시청의 **출석 NPC**(기본 이름 "시청 서기 하루")에게 말을 걸면 출석부가 열립니다. 하루에 한 번 **출석하기**를 누르면 그날의 보상을 받습니다.
- 출석일은 **한국 시간 오전 6시**에 바뀝니다. 주간 출석은 월요일 오전 6시에 새로 시작합니다 (3.7.0 의 오전 9시에서 바뀜).
- **일일 보상**: 기본 28일 주기(7·14·21일째는 큰 보상, 28일째는 토지 문서). 28일을 다 받으면 다시 1일차부터.
- **주간 보상**: 이번 주에 3일·5일·7일 출석하면 각각 받습니다 (연속이 아니어도 됨).
- **빠졌을 때**: 연속 출석 중 하루를 처음 빠지면 한 번은 진행도를 지켜 주고, 접속할 때 경고합니다. 그 뒤로는 하루만 빠져도 0일차로 초기화됩니다. 처음부터 이틀 이상 빠지면 바로 초기화됩니다. 초기화된 뒤 새 연속 출석에서는 다시 한 번 봐줍니다 (설정에서 '처음 한 번뿐'으로 바꿀 수 있음).
- **일일 출석 진행도 복구권**: 출석 NPC 의 **출석 상점**(30,000G)에서 팝니다. 초기화된 때부터 24시간 안에 우클릭(또는 출석부의 '복구권 사용')하면 진행도를 되돌립니다. 한 번 쓰면 24시간 동안 다시 못 씁니다. 되팔 수 없습니다.
- 출석은 NPC 에게서만 할 수 있습니다. `/rtshop attendance` 로는 진행도만 볼 수 있고, 접속할 때 아직 출석하지 않았으면 채팅으로 알려 줍니다.
- **편집 (OP)**: 출석부의 '편집' 또는 `/rtshop attendance edit`. 날마다 Gold·아이템(목록에서 고르기)·특별한 날 표시, 주간 보상 단계, NPC 이름·기준 시각·봐주기·복구권 시간을 고칠 수 있고 저장하면 바로 적용됩니다 (`config/rtshop/attendance.json`). 복구권 가격은 `config/rtshop/shops/attendance_shop.json`.

### 뽑기 (3.8)

- **뽑기 상인**에게 말을 걸면 뽑기 창이 열립니다. 무기 · 펫 · 장신구 × 일반 · 중급 · 고급 뽑기.
- **티켓**: 창의 '티켓 사기'(뽑기 티켓 상점)에서 Gold 로 삽니다 — 일반 1,000G · 중급 5,000G · 고급 20,000G. 티켓 한 장에 한 번, 10회 뽑기는 희귀 이상 1개 보장. 티켓은 주고받을 수 있습니다.
- **등급과 확률** (기본값, 아이템이 없는 등급은 빼고 계산): 일반 뽑기 일반 72% · 고급 25% · 희귀 3% / 중급 뽑기 일반 45% · 고급 40% · 희귀 14% · 영웅 1% / 고급 뽑기 고급 55% · 희귀 39.5% · 영웅 5% · 전설 0.5%. 창의 '확률표 보기'에서 아이템 하나하나의 확률을 볼 수 있습니다.
- **목록**: 처음 켤 때 모드 아이템을 성능 순으로 자동 분류합니다 (무기: 공격력·희귀도, 장신구: Curios 칸 아이템·희귀도, 펫: 길들일 수 있는 동물·체력). 보스 무기(Cataclysm, EPIC 희귀도), 총(TaCZ), 꾸미기 모자(Simple Hats)는 뺍니다.
- **펫**은 '펫 소환권'으로 나옵니다. 땅을 우클릭하면 길들여진 채로 나타납니다.
- **뽑은 아이템은 상점에 팔 수 없습니다.** 대신 '분해'로 조각을 받고, '조각 교환'에서 원하는 아이템과 바꿉니다 (분해: 일반 1 · 고급 3 · 희귀 10 · 영웅 40 · 전설 150 / 교환: 10 · 30 · 100 · 400 · 1,500).
- 전설을 뽑으면 서버 전체에 알립니다. 천장(일정 횟수 안에 보장)은 아직 넣지 않았고, 뽑은 횟수만 기록해 둡니다.
- **편집 (OP)**: 뽑기 창의 '편집' 또는 `/rtshop gacha edit`. 아이템·펫을 목록에서 골라 넣고 등급·가중치·수량을 정하고(손에 든 인챈트 아이템도 그대로), 등급 확률·10회 보장·조각 값을 바꾸고, 모의 뽑기 1,000번으로 확인합니다. '자동 분류로 다시 채우기'도 있습니다 (`config/rtshop/gacha.json`).

### 퀘스트 편집기 (OP, 3.2)

`/rtshop quest edit` 로 엽니다. 게임 안에서 퀘스트와 퀘스트 NPC 를 만들고 고치고 지울 수 있고, **저장하면 바로 적용**됩니다.

- **퀘스트 / NPC** 버튼으로 목록을 바꿉니다. 빨간 항목은 지금 쓰이지 않는 퀘스트이고, 마우스를 올리면 이유가 보입니다.
- 탭: **기본**(제목·주는 NPC·선행 퀘스트·표식), **이야기**(받기 전/진행 중/완료할 때 글, 줄바꿈 가능), **목표**(최대 4개), **보상·선택지**(Gold·아이템 3개·표식·선택지 3개).
- 아이템·몬스터는 ID 를 칠 필요 없이 칸을 누르면 **선택 목록**이 열립니다. 아이템은 아이콘 격자, 몬스터는 이름 목록이고 이름·ID·`@모드이름`으로 검색합니다. 목록에 없는 ID 나 `#태그`는 검색칸에 적고 Enter.
- 도우미 버튼: **손**(손에 든 아이템), **근처**(가까운 몬스터), **여기**(지금 좌표). NPC·목표 종류·외형처럼 여러 개 중에서 고르는 칸은 누르면 목록이 펼쳐집니다.
- **모드 조건 (3.6.2)**: 목표와 보상 아이템마다 "항상 / ○○ 있을 때 / ○○ 없을 때" 를 고를 수 있습니다. 조건이 맞지 않는 목표·보상은 그 서버에서 빠집니다.
- **모드 도움말 줄**: 이야기 칸에서 "모드 도움말 ▼" 로 모드를 고르면 `[모드ID] ` 로 시작하는 줄이 붙습니다. 이 줄은 그 모드가 있을 때만 "◆ 모드 이름" 머리말과 함께 보입니다.
- **키 넣기**: "키 넣기 ▼" 로 조작 키를 고르면 `{key:키 이름}` 이 들어가고, 퀘스트 창에서는 그 플레이어가 실제로 정해 둔 키(예: [R])로 바뀌어 보입니다.
- **표식**: 보상이나 선택지로 얻는 이름표입니다. 다른 퀘스트의 '필요 표식'에 적으면 그 표식이 있어야 보이고, '막는 표식'에 적으면 숨겨집니다.
- NPC 탭의 **여기 소환**으로 만든 NPC 를 바로 세울 수 있고, 이름을 바꾸면 이미 세워 둔 NPC 이름도 바뀝니다.
- 안전장치: 다른 퀘스트가 선행 조건으로 쓰는 퀘스트, 퀘스트에 쓰이는 NPC 는 지울 수 없습니다. 이미 있는 퀘스트의 ID 는 바꿀 수 없습니다(진행 기록이 ID 에 묶여 있음).
- 저장 위치: 원래 있던 파일(`config/rtshop/quests/`)에 그대로, 새로 만든 것은 `my_quests.json`. **모드를 업데이트해도 고친 내용은 덮어쓰지 않습니다.** 지운 기본 파일도 다시 깔지 않습니다.
- 메모장으로 JSON 을 직접 고쳐도 되고, 그 뒤 `/rtshop reload` 하면 됩니다.

## 가격 원칙

1. 원재료(만들 수 없는 것)는 가격표 값에 팔고 그 50% 에 매입합니다 (별·무게가 붙은 수확물은 위 표대로).
2. 만들 수 있는 물건(음식·장비·가공품)은 **재료 원가만큼** 매입하고, 상점 판매가는 그 2배 이상입니다.
   재료를 사서 만들어 팔면 본전 이상이고, 만들어 되파는 것만으로 돈이 불어나지도 않습니다.
3. 요리 재료로 쓰는 가공품(설탕, 기름, 유리병, 그릇 등)은 원가 이하로 팝니다.
4. 자동 농장으로 무한히 쌓이는 것(사탕수수, 수박, 호박, 몹 드롭 등)은 값이 아주 낮고, 대나무·켈프·돌·모래 같은 것은 매입하지 않습니다.

`/rtshop export` 를 실행하면 `config/rtshop/export/` 에 실제 적용된 가격과 점검 결과(`audit.txt`)가 저장됩니다.

## 경제 보호 장치 (`config/rtshop/economy.json`)

| 설정 | 기본값 | 설명 |
|------|--------|------|
| `playerKillOnlyDrops` | 철 골렘, 좀비화 피글린, 가디언 | 플레이어가 직접 잡지 않으면 전리품이 나오지 않습니다. 자동 농장으로 철·금·물고기가 무한히 쌓이는 것을 막습니다. `[]` 로 비우면 바닐라와 같습니다 |
| `villagerTrading` | `filtered` | 주민·떠돌이 상인의 거래 중 "상인 NPC 가 매입하는 물건을 파는 거래"만 사라집니다 (에메랄드로 빵·철 갑옷을 받아 되파는 무한 돈벌이 방지). 인챈트 책이나 에메랄드를 받는 거래는 그대로입니다. `allow` = 바닐라 그대로, `block` = 주민 거래 전체 차단. 한 번 사라진 거래는 설정을 바꿔도 그 주민에게 되돌아오지 않습니다 |

## 설정 파일 (`config/rtshop/`)

| 파일 | 내용 |
|------|------|
| `shops/*.json` | 상점별 품목과 가격. 파일 이름이 상점 ID (`/rtshop npc <ID>`). 새 파일을 만들면 새 상점이 됩니다 |
| `pricing.json` | 재판매 비율, 조리 종류별 마진·수고비, 물고기 무게 배율 |
| `farming.json` | 씨앗 규칙, 별 등급 확률·배율, 괭이 수확 범위 |
| `land.json` | 토지 크기, 한 사람당 최대 개수, PIN 자릿수 등 |
| `economy.json` | 시작 Gold, 사망 손실, 보호 장치 |
| `attendance.json` | 출석 보상 표, 기준 시각, 봐주기, 복구권 시간 (게임 안 편집기로도 수정) |
| `gacha.json` | 뽑기 목록·등급 확률·조각 값 (게임 안 편집기로도 수정) |
| `recipes.json` | 막은 조합법, 직접 만든 조합법 (`/rtshop recipes`) |
| `loot.json` | 상자 전리품 규칙: 빼기·확률 바꾸기·넣기 (`/rtshop loot`) |
| `enhance.json` | 강화 단계별 확률·재료·Gold, 보석 묶음, 능력치 증가율 |
| `pvp.json` | PvP 켜기/끄기: 마을 밖 허용 여부, PvP 가능 구역·안전 구역, 전투 잠금 시간 (게임 안 `/rtshop pvp ...` 로 수정) |
| `restaurant.json` | 식당 주인: 판매 보너스, 팔 수 있는 직업, 식품 상인의 요리 판매 여부 |
| `raid.json` | 주간 레이드: 보스·배율·조건·문구·보상·구역 위치 (게임 안 `/rtshop raid edit`) |

수정 후 `/rtshop reload` 로 적용합니다. `farming.json` 은 클라이언트에도 같은 내용을 넣어야 아이템 설명이 맞게 나옵니다.

## 알아 둘 점

- 음식값은 "가장 싼 방법" 기준이라, 여러 재료 중 하나를 고르는 조리법(예: 아무 채소)에 비싼 재료를 쓰면 그만큼 덜 남습니다.
- 가격표에 없는 다른 모드의 재료는 낮은 추정가(기본 2G)로 계산됩니다. 제값을 쳐 주려면 상점 파일에 가격을 적어 주세요 (`audit.txt` 에 목록이 나옵니다).
- 업데이트 전에 심어 둔 작물은 그대로 자라지만 수확물에 별이 붙지 않습니다.
- 장비 상인은 다른 모드의 무기·방어구도 공식 가격으로 팝니다 (보스 장비는 수십만 G). 팔지 않게 하려면 `shops/blacksmith.json` 의 `exclude` 에 `"cataclysm:*"` 처럼 모드 ID 를 적으세요.
- 가격은 서버 운영 중에 조정해야 하는 값입니다. 기본값은 "생활 직업 1시간 수입 약 20,000G" 를 기준으로 잡았습니다.

## 빌드와 검증

`main` 에 올라가면 GitHub Actions 가 jar 를 빌드하고 아래 점검을 돌린 뒤 Releases 에 올립니다.

1. **서버 자체 점검** (통과해야 배포됨): 테스트 서버를 띄워 가짜 플레이어로 경제·수표·상점·농사·토지·PIN·가격 규칙을 확인합니다.
2. **화면 점검**: 실제 클라이언트를 띄워 HUD, 상점, 은행, 토지 관리, PIN 화면을 열어 보고, 구매·판매·입금·권한 변경·우클릭 수확을 실제 패킷으로 실행합니다.
3. **요리·농사 모드 점검**: Farmer's Delight, Kaleidoscope Cookery/Tavern, Hands-On Delight, Farm & Charm, Starcatcher, Better Farming++ 최신판과 함께 실제 포지 서버에서 1번을 다시 돌립니다.
4. **모드팩 전체 점검 (서버)**: 모드팩 "RT1 - 2" 의 모드를 매니페스트 버전 그대로 받아 포지 47.4.28 서버에서 1번을 다시 돌립니다
   (전용 서버에서 켜지지 않는 클라이언트 전용 모드 Oculus, Forgematica, MaFgLib, Cubes Without Borders 와 셰이더·리소스팩은 제외).
5. **모드팩 전체 점검 (클라이언트)**: 모드팩의 모든 모드와 Arcane Vortex 를 넣은 실제 클라이언트를 띄워 2번을 다시 돌립니다.

3~5번은 참고용이라 실패해도 배포는 진행됩니다 (Actions 화면에서 결과와 스크린샷을 볼 수 있습니다).

`/rtshop export` 를 실행하면 `config/rtshop/export/` 에 실제 적용된 가격표와 점검 보고서(`audit.txt`)가 만들어집니다.
직접 빌드하려면 JDK 17 에서 `./gradlew build` (결과물: `build/libs/`).

## 모드팩 참고: Distant Horizons 와 Chunky

RT Shop 과는 무관하지만, 5번 점검 환경에서 확인한 내용입니다.

- 모드팩에 **Distant Horizons 3.3.3 과 Chunky 1.3.146 을 함께** 넣으면 월드에 들어가는 순간
  `java.lang.IllegalStateException: Chunky is not loaded.` (Distant Horizons 의 `ChunkyAccessor`) 로 게임이 꺼집니다.
- **Chunky 를 빼면** 같은 모드 구성(Farsight, Oculus 1.8.0, Arcane Vortex 0.7.10 포함)에서 정상 실행됩니다.
- 그래서 순서는 "Chunky 로 미리 생성 (Distant Horizons 없이) → Chunky 를 빼고 Distant Horizons 추가" 입니다.
