# RT Shop 2.1 (Forge 1.20.1) — Gold 경제 + 상인 4명 + 은행

RT1 - 2 모드팩(Forge 1.20.1, 47.4.x)용 독립 모드입니다. 1.0의 상점 화면(검색·카테고리·정렬·격자/목록·50% 재판매·인벤 가득 참 구매 차단)은 그대로 두고, 화폐를 가상 화폐 **Gold(G)** 로 바꾼 뒤 경제 시스템을 얹었습니다.

> 이 모드는 작업 환경에서 **컴파일·실행 테스트를 하지 못했습니다** (Forge 저장소 접속 불가).
> 빌드나 실행 중 오류가 나면 메시지를 그대로 알려주세요.

## 무엇이 들어 있나

| 기능 | 내용 |
|------|------|
| 화폐 | 가상 화폐 Gold(G). 아이템이 아니라 서버에 저장되는 숫자 (`world/data/rtshop_economy.dat`) |
| HUD | 화면 오른쪽 중간(미니맵 아래, 스크린샷의 노란 박스 자리·크기)에 G 금화 아이콘 + 보유량 |
| 사망 손실 | 사망 시 **소지금**의 5~50%를 무작위로 잃음 (예금은 안전) |
| 은행 | 은행 NPC를 우클릭했을 때만 이용. 입금/출금, 이자 없음 |
| 상인 4명 | 농작물 상인 · 수산물 상인 · 장비 상인 · 잡화 상인 |
| 거래 | 모든 구매/판매는 Gold로. 판매가는 구매가의 50% (소수점 버림) |

스크린샷에는 상인이 "4명"인데 종류는 3가지만 적혀 있어서, 네 번째는 건축 자재·광물·도구·음식을 파는 **잡화 상인**으로 정했습니다. 필요 없으면 `config/rtshop/shops/general.json`을 지우면 됩니다.

## 2.1에서 달라진 점

- 아이템을 좌클릭하면 수량 입력 창이 열려 원하는 개수만큼 구매·판매할 수 있습니다. 2.0의 설정 파일과 월드 데이터(Gold, 예금)는 그대로 쓰입니다.

## 1.0에서 달라진 점

- 화폐가 에메랄드 아이템 → Gold. `config/rtshop/shop.json`(구버전)은 더 이상 쓰지 않습니다.
- `/shop` 명령어와 단축키는 없앴습니다. 상점은 **상인 NPC 우클릭**으로만 열립니다 (OP는 `/rtshop open <상점>`으로 테스트 가능).
- NPC에서 약 10블록 이상 멀어지면 거래가 거부됩니다.

## 1. 설치

1.0과 같습니다. 소스 프로젝트이므로 먼저 jar로 빌드합니다.

**방법 A — GitHub (추천)**
1. GitHub에 새 저장소를 만들고 이 폴더의 내용 전체를 올립니다 (숨김 폴더 `.github` 포함).
2. Actions 탭의 `build`가 끝나면 맨 아래 Artifacts에서 `rtshop-jar`를 받습니다.

**방법 B — 내 컴퓨터**
1. JDK 17 설치 (21 이상이면 빌드 실패).
2. 이 폴더에서 `gradlew.bat build` (Mac/Linux는 `./gradlew build`).
3. 결과물: `build/libs/rtshop-forge-1.20.1-2.1.1.jar`

**모드팩에 넣기**
- jar를 프로필의 `mods` 폴더에 넣습니다. 멀티플레이는 **서버와 모든 클라이언트**에 같은 jar가 필요합니다.
- 이전 버전(1.0, 2.0) jar가 있으면 반드시 지우세요 (같은 모드 ID라 둘 다 있으면 실행되지 않습니다).
- 처음 실행하면 `config/rtshop/` 아래에 설정 파일이 생깁니다.

## 2. 처음 세팅 (관리자, OP 권한)

NPC를 세울 자리에 서서 다음을 입력합니다.

```
/rtshop npc farmer       농작물 상인
/rtshop npc fisher       수산물 상인
/rtshop npc blacksmith   장비 상인
/rtshop npc general      잡화 상인
/rtshop npc bank         은행원
```

- 움직이지 않고 무적인 주민이 소환됩니다. 우클릭하면 상점(또는 은행)이 열립니다.
- 제거: `/kill @e[tag=rtshop_shop_farmer,limit=1,sort=nearest]` (은행원은 `tag=rtshop_bank`)
- 이미 있는 다른 몹을 상인으로 쓰려면: `/tag <엔티티> add rtshop_shop_farmer`

그다음 `/rtshop export`를 한 번 실행해 보세요. 자동 규칙이 실제로 어떤 아이템을 얼마에 잡았는지 `config/rtshop/export/상점ID.json`에 저장됩니다. **모드 아이템 가격은 이 파일로 확인하는 것이 가장 정확합니다.**

## 3. 플레이어 사용법

- **Gold 확인**: 화면 오른쪽 HUD, 또는 `/rtshop balance` (예금 포함).
- **처음 접속**: 100 G 지급 (설정 가능).
- **상점**: 상인 우클릭 → 오른쪽 위 `구매`/`판매` 탭.
  - **좌클릭 → 수량 입력 창**: 숫자를 직접 입력하거나 `-10` `-1` `+1` `+10` `최대` 버튼(또는 마우스 휠)으로 조절한 뒤 `구매`/`판매` (Enter로 확인, Esc로 취소)
  - 창에는 단가, 지금 거래 가능한 최대 수량, 합계(판매는 받는 금액)가 표시됩니다. 최대 수량은 구매 시 소지금과 인벤토리 빈 공간, 판매 시 보유 수량으로 정해지며 넘으면 확인 버튼이 눌리지 않습니다.
  - 빠른 거래: 우클릭 10개 · Shift+클릭 한 묶음(판매는 전부)
  - 가격이 빨간색 = Gold 부족, 어둡고 "가득 참" = 인벤토리 공간 부족 (구매 불가)
- **은행**: 은행원 우클릭 → 금액 입력 후 `입력한 금액 입금`/`입력한 금액 출금`, 또는 `소지금 전부 입금`/`예금 전부 출금`.
- **송금**: `/rtshop pay <플레이어> <금액>` (소지금에서 차감).
- **사망**: 소지금의 5~50%가 사라지고 채팅에 손실액이 표시됩니다. 예금은 그대로입니다.

판매 규칙:
- 각 상인은 자기가 취급하는 아이템만 사 줍니다.
- 장비·도구는 새것(내구도 닳지 않음, 인챈트 없음)만 판매할 수 있습니다.
- 물고기와 Starcatcher 아이템은 크기·무게 같은 추가 정보가 붙어 있어도 판매됩니다.

## 4. 경제 설계와 임시 가격

**기준 가치** — 철괴 40 G를 기준으로 재료 가격을 잡고, 완제품은 재료비와 비슷하게 맞췄습니다.

| 분류 | 대표 가격 (구매가, G) |
|------|----------------------|
| 광물/재료 | 석탄 10 · 구리 12 · 철 40 · 금 80 · 에메랄드 120 · 다이아 300 |
| 농작물 | 밀 6 · 당근 6 · 감자 5 · 호박 15 · 양배추 10 · 토마토 8 · 쌀 6 · 건초 54 |
| 씨앗 | 밀 씨앗 2 · 그 외 씨앗 4 · 묘목 10~20 |
| 수산물 | 대구 16 · 연어 20 · 열대어 40 · 복어 45 · Starcatcher 아이템 기본 40 |
| 해양 자원 | 잉크 12 · 프리즈머린 20~30 · 앵무조개 400 · 바다의 심장 3,000 |
| 건축 | 원목 8 · 판자 2 · 돌 3 · 벽돌 12 · 책장 90 |
| 음식 | 빵 20 · 구운 감자 9 · 황금 당근 80 · 황금 사과 700 |

**능력치 기반 자동 가격** — 모드팩의 무기·방어구는 수가 많아 ID를 일일이 적지 않고, 게임에 등록된 아이템의 실제 능력치로 계산합니다.

| 종류 | 공식 | 예 |
|------|------|----|
| 근접 무기 | 4 × 공격력² × 품질 | 철 검 100 · 다이아 검 625 · 네더라이트 검 3,150 |
| 방어구 | (55×방어력 + 250×강인함 + 1500×넉백저항) × 품질 | 철 흉갑 320 · 다이아 흉갑 1,700 · 네더라이트 흉갑 8,000 |
| 원거리 | 120 × 품질 | 활 170 · 쇠뇌 195 |
| 방패 | 150 × 품질 | 방패 190 |
| 도구 | 130 × 품질 (괭이 90) | 철 곡괭이 130 · 다이아 곡괭이 565 · 철 괭이 90 |
| 음식 | (2 + 허기×2 + 허기×포화×3) × 0.6 | 스테이크 22 |

품질 = 내구도 계수 × 희귀도(일반 1 / 고급 1.5 / 희귀 2.5 / 영웅 4) × 화염 저항이면 3배.
내구도 계수는 철(250)을 1로 두고 (내구도/250)^0.8, 부서지지 않는 아이템은 4.

**돈의 흐름**
- 버는 방법: 농사·낚시·채광·사냥으로 얻은 것을 상인에게 판매 (구매가의 50%).
- 쓰는 곳: 장비와 재료 구매. 사망 손실로 Gold가 경제에서 빠져나갑니다.
- 무한 돈벌이 방지: ① 되팔면 항상 50% 손해 ② 한 아이템은 한 상점에서만 취급(상점 간 가격 차 없음) ③ 바닐라 조합법 기준으로 "재료를 사서 만들어 팔면 이득"인 경우가 없도록 확인했습니다.

**알아 둘 한계 (임시 가격인 이유)**
- 모드 아이템은 실제 게임에서 확인하지 못했습니다. `/rtshop export`로 결과를 보고 조정하세요.
- 마법 지팡이·로브처럼 주문력으로 강한 장비는 공격력·방어력이 낮아 싸게 잡힐 수 있습니다.
- 보스 드롭 무기(Cataclysm 등)도 장비 상인 목록에 들어갑니다. 팔고 싶지 않으면 `blacksmith.json`의 `exclude`에 `"cataclysm:*"`처럼 추가하세요.
- TaCZ 총기는 한 아이템에 NBT로 종류가 나뉘는 구조라 제외했습니다 (`tacz:*`). Artifacts·Relics도 제외했습니다.
- Starcatcher 물고기는 종류와 무관하게 기본 40 G입니다 (희귀도가 아이템에 설정돼 있으면 배율 적용).
- 모드 요리의 조합 차익까지는 전부 확인하지 못했습니다.

## 5. 설정 파일 (`config/rtshop/`)

| 파일 | 내용 |
|------|------|
| `economy.json` | `startingGold`(100), `deathLossMinPercent`(5), `deathLossMaxPercent`(50), `bankNpcName`, `npcRange`(10) |
| `client.json` | Gold HUD 위치·크기 (각 플레이어 컴퓨터에서 설정) |
| `shops/*.json` | 상점. **파일 이름이 상점 ID** — 새 파일을 만들면 새 상인이 됩니다 |
| `export/*.json` | `/rtshop export` 결과 (읽기용) |

상점·경제 설정은 수정 후 `/rtshop reload`로 다시 불러옵니다 (서버 재시작 불필요).

**HUD 위치** — `client.json`의 값은 화면 크기에 대한 비율(0~1)입니다. 기본값은 보내주신 스크린샷의 노란 박스 자리(오른쪽 끝·위쪽 기준)에 약 75% 크기로 잡은 것이라 해상도나 GUI 배율이 달라도 같은 자리·같은 비율입니다. `hudX`/`hudY`는 박스 왼쪽 위 모서리이고, 수정 후 게임을 다시 시작해야 반영됩니다.

**상점 파일 형식**

```json
{
  "title": "수산물 상점", "npcName": "수산물 상인", "profession": "fisherman", "sellRatio": 0.5,
  "categories": [ { "id": "fish", "name": "수산물", "icon": "minecraft:cod" } ],
  "items": [ { "item": "minecraft:cod", "price": 16, "category": "fish", "looseSell": true } ],
  "auto":  [ { "match": { "mod": "starcatcher" }, "category": "fish", "formula": "auto", "price": 40, "looseSell": true } ],
  "exclude": [ "somemod:*", "minecraft:trident" ]
}
```

- `items`: 가격을 직접 정한 아이템. `nbt`(SNBT 문자열)도 쓸 수 있습니다.
- `auto.match`: `mod`/`mods`(모드 ID), `tag`/`tags`(아이템 태그), `class`/`classes`(`weapon`, `ranged`, `armor`, `shield`, `tool`, `hoe`, `fishing_rod`, `food`, `gear`). 여러 조건을 쓰면 모두 만족해야 합니다.
- `auto.formula`: `fixed`(price 그대로) · `gear` · `food` · `auto`(장비/음식이면 공식, 아니면 price×희귀도). `multiplier`로 배율 조정.
- `looseSell`: 판매 시 NBT 무시. `profession`: NPC 주민 직업 외형.
- 우선순위: 직접 적은 `items`가 `auto`보다 먼저, 상점 간에는 파일 이름 순서가 먼저입니다. 자동 가격이 마음에 안 드는 아이템은 `items`에 직접 적으면 됩니다 (export 파일의 줄을 복사해 붙이면 편합니다).

## 6. 명령어

| 명령어 | 권한 | 설명 |
|--------|------|------|
| `/rtshop balance` | 모두 | 내 소지금·예금 |
| `/rtshop pay <플레이어> <금액>` | 모두 | 송금 |
| `/rtshop npc <상점ID\|bank>` | OP | NPC 소환 |
| `/rtshop reload` | OP | 설정 다시 불러오기 |
| `/rtshop export` | OP | 현재 가격표 내보내기 |
| `/rtshop open <상점ID>` | OP | NPC 없이 상점 열기 (테스트용) |
| `/rtshop gold give\|take\|set <플레이어> <금액>` | OP | 소지금 조정 |
| `/rtshop gold check <플레이어>` | OP | 다른 플레이어 잔액 확인 |

## 7. 충돌 방지

- 모드 ID `rtshop`, 채널 `rtshop:main`만 사용. 믹스인·코어모드·다른 모드 API 의존 없음.
- 새 블록·아이템·엔티티 등록 없음 (NPC는 바닐라 주민 + 태그). 단축키 등록 없음.
- 다른 모드 아이템을 훑어볼 때 예외가 나면 그 아이템만 건너뜁니다.
- 모드팩의 **wd's Selling Bin**은 별도의 판매 수단이라 그대로 함께 동작합니다. Gold와는 연결되지 않습니다.

## 8. 문제 해결

- **빌드 실패 `Unsupported class file major version`** → JDK 17로 빌드하세요.
- **HUD가 미니맵과 겹치거나 어긋남** → `client.json`의 `hudX`/`hudY`를 조정.
- **상인을 눌러도 주민 거래창이 뜸** → 서버에 모드가 없거나 태그가 없는 주민입니다.
- **상점에 아이템이 안 보임** → `logs/latest.log`에서 `[rtshop]`을 검색하면 상점별 로드 개수와 건너뛴 아이템이 나옵니다.
- **Starcatcher 탭이 비어 있음** → 모드 ID가 `starcatcher`가 아닐 수 있습니다. F3+H로 아이템 ID 앞부분을 확인해 `fisher.json`의 `mod` 값을 바꾸세요.
