# 골디아 연대기 설정집 (스토리 대개편 기준서)

전체 문서: https://claude.ai/artifact/KW9iD7UHVNE7LCtbuP5QDC  (Docs 문서 id 95d66ee9-183d-48dc-939e-9f4dd1a6127f, 본문 노드 4b2dcec7-19bc)

핵심 결정 (요약):
- 불 = 기억. 불에 먹힌 이름은 세상에서 잊힌다. 이름을 잃으면 죽지 못하고 '시든다'(언데드·위더의 뿌리). 기록관의 잉크(불씨의 재)로 적은 이름은 불이 먹지 못한다.
- 천 년 전: 일곱 왕이 최초의 불꽃을 여섯 '눈' + '심지'(아르덴=이그니스)로 나눔. 나누려면 이름 하나를 통째로 먹여야 했고, 여덟째 왕 오렐이 스스로 자기 이름을 내놓음. "때가 되면 놓아다오"(서약의 지워진 셋째 줄).
- 오렐의 왕국 = 허공(엔드), 백성 = 엔더맨, 땅에 없던 후손 = 잿빛 무리(약탈자). 지옥 = 가라앉은 칼데라 왕국, 지옥 요새 = 불꽃 기사단의 방벽, 위더 스켈레톤 = 초소를 지킨 기사들, 위더(검은 별) = 세 대장(하르겐·이졸데·메르윈)의 「세 머리의 서약」으로 만든 '잊힘의 무기'. 헬바르(Bosses'Rise) = 서약을 거부한 부단장.
- 에르윈 = 오렐의 제자. 불꽃에 손을 넣어 낙인(이름의 6번째 글자). 스승의 이름만 떠오르지 않고 죽지도 못함. 수도회·기억의 문을 만든 사람. 문 안에서 수호자가 쓰러질 때마다 불의 몫이 그의 낙인으로 흐름.
- 벨로크(일루저너) = 사형. 거울 속으로 숨음. 에르윈이 진실(스승이 스스로 택함)을 알면 무너질까 봐 연대기를 "일곱이 쫓아냈다"로 고쳐 씀(다정한 거짓말). 룬 제단을 만듦: 다섯 룬석 = 오렐의 이름 8글자 중 5글자. 7번째 = 엘레나의 잉크 점, 8번째 = 용의 마지막 울음.
- 기억의 문: 불씨로 여는 '불꽃이 기억하는 존재'의 방. 문 없이 수호자를 건드리면 되먹임(얼어붙은 바다). 문의 값: 잠재운 존재의 이름을 세상이 잊기 시작 → 이사벨이 매번 이름을 적음.
- 로란: 다리 부상, 2장 지역만 앎. 1장은 이사벨 동행 + 펠릭스(엘레나의 동행, 기억이 조각조각) + 현장 조사.
- Bosses'Rise 배치: 헬바르 1장(지옥), 스코르 2장(설원), 네라키스 3장(녹는 바다), 시로크 4장(사막), 애쉬로드 종장(아르덴의 용). modid block_factorys_bosses, CF 1314084 / 파일 8123166.
- 룬 제단 잠금: 3장 끝(코넬리아 선장실의 금 간 구체)에서 획득·해금.
- 새 시스템: 장소 조사(INSPECT 목표, 흔적 오브젝트, 조사 수첩), 동행 NPC(퀘스트 장소에 개인 스폰·전투·완료 시 소멸), 용 소환식(귀환의 의식), 이름 적기 장면.
- 용어: 스토리 글에서 네더 → 지옥.
- 릴리스 계획: 3.32 시스템 / 3.33 서장+1장 / 3.34 2장 / 3.35 3장 / 3.36 4장 / 3.37 종장+숨은 이야기.

확정 (사용자 답변, 2026-11-24):
- Bosses'Rise 는 모드팩(RT1-2 #9)에 들어 있다. 다섯 보스 배치 그대로 진행.
- 새 이름(오렐·하르겐·이졸데·메르윈·헬바르·벨로크 등) 유지.
- 카스를 살려 보내는 선택지를 둔다: story_1_30 → 표식 ch1_kas_spared / ch1_kas_held.
  회수 계획: spared → 종장 「끌려간 기록관」에서 잿빛 무리가 길을 터 준다("빚은 진 쪽이 기억한다"), 숨은 이야기에서 카스가 무리의 노래 원본을 가져옴.
  held → 4장 쉬는 막에서 카스의 감방이 비어 있고 벽에 노래만 남음(에르윈이 풀어 줌: 그 노래의 '왕'이 누구인지 그만 알아봄).
- 룬 제단 개방 시점은 3장 끝(「거울」 막)으로 확정. story_systems.json 의 altarLockFlag 를 3.35 에서 story_ch3_done 으로 기본 설정.
- 헬바르는 봉인에 묶인 수호자가 아니라 스스로 남은 사람 → 기억의 문 없이 자기 투기장에서 싸운다(되먹임 없음).
- 4판 진행도 이주: story_v4 표식 (QuestManager.migrateStory4).
- 대사 텍스트 내보내기: python3 tools/export_story_txt.py <파일> [ID 접두어…]. 장을 끝낼 때마다 사용자에게 txt 전달, 전부 끝나면 합본.
