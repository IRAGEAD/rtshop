# 베스탈리아 연대기 설정집 (스토리 대개편 기준서)

전체 문서: https://claude.ai/artifact/KW9iD7UHVNE7LCtbuP5QDC  (Docs 문서 id 95d66ee9-183d-48dc-939e-9f4dd1a6127f, 본문 노드 4b2dcec7-19bc)

핵심 결정 (요약):
- 불 = 기억. 불에 먹힌 이름은 세상에서 잊힌다. 이름을 잃으면 죽지 못하고 '시든다'(언데드·위더의 뿌리). 기록관의 잉크(불씨의 재)로 적은 이름은 불이 먹지 못한다.
- 천 년 전: 일곱 왕이 최초의 불꽃을 여섯 '눈' + '심지'(아르덴=이그니스)로 나눔. 나누려면 이름 하나를 통째로 먹여야 했고, 여덟째 왕 오렐이 스스로 자기 이름을 내놓음. "때가 되면 놓아다오"(서약의 지워진 셋째 줄).
- 오렐의 왕국 = 허공(엔드), 백성 = 엔더맨, 땅에 없던 후손 = 잿빛 무리(약탈자). 지옥 = 가라앉은 칼데라 왕국, 지옥 요새 = 불꽃 기사단의 방벽, 위더 스켈레톤 = 초소를 지킨 기사들, 위더(검은 별) = 세 대장(하르겐·이졸데·메르윈)의 「세 머리의 서약」으로 만든 '잊힘의 무기'. 헬바르(Bosses'Rise) = 서약을 거부한 부단장.
- 에르윈 = 오렐의 제자. 불꽃에 손을 넣어 낙인(이름의 6번째 글자). 스승의 이름만 떠오르지 않고 죽지도 못함. 수도회·기억의 문을 만든 사람. 문 안에서 수호자가 쓰러질 때마다 불의 몫이 그의 낙인으로 흐름.
- 벨로크(일루저너) = 사형. 거울 속으로 숨음. 에르윈이 진실(스승이 스스로 택함)을 알면 무너질까 봐 연대기를 "일곱이 쫓아냈다"로 고쳐 씀(다정한 거짓말). 룬 제단을 만듦: 다섯 룬석 = 오렐의 이름 8글자 중 5글자. 7번째 = 엘레나의 잉크 점, 8번째 = 용의 마지막 울음.
- 기억의 문: 불씨로 여는 '불꽃이 기억하는 존재'의 방. 문 없이 수호자를 건드리면 되먹임(얼어붙은 바다). 문의 값: 잠재운 존재의 이름을 세상이 잊기 시작 → 이사벨이 매번 이름을 적음.
- 로란: 다리 부상, 2장 지역만 앎. 1장은 이사벨 동행 + 펠릭스(엘레나의 동행, 기억이 조각조각) + 현장 조사.
- Bosses'Rise 배치: 헬바르 1장(지옥), 스코르 2장(설원), 네라키스 3장(녹는 바다), 시로크 4장(사막), 애쉬로드 종장(아르덴의 용). modid block_factorys_bosses, CF 1314084 / 파일 8123166.
- 룬 제단 잠금: 3장 끝(코넬리아 선장실의 금 간 구체)에서 획득·해금.
- 새 시스템: 장소 조사(INSPECT 목표, 흔적 오브젝트, 조사 수첩), 동행 NPC(퀘스트 장소에 개인 스폰·전투·완료 시 소멸), 용 소환식(귀환의 의식), 이름 적기 장면.
- 용어: 스토리 글에서 네더 → 지옥.
- 릴리스 계획: 3.32 시스템 / 3.33 서장+1장 / 3.34 2장 / 3.35 3장 / 3.36 4장 / 3.37 종장+숨은 이야기.

- 10회 뽑기 없음(한 번에 한 장). 「오늘의 룬」 없음(옛 파일의 blessing 은 버림).
- 확률표의 첫 칸(일반 등급 자리) = 실패: 스킬북은 아무것도 안 나오고(MagicConfig.FAIL), 인챈트는 주문서만 쓰이고 장비는 그대로(FAIL_ENCH). 기본 스킬북 {40, 41.98, 15.9, 1.92, 0.18, 0.02}, 인챈트 {50, 32, 13, 4.3, 0.7}. 목록의 일반 등급은 고급으로 올라간다. 인챈트 등급은 고급~전설(옛 설정 1 → 2 로 옮길 때 한 칸씩 올림, 방어구·도구 인챈트 덧붙임, 백업 magic_gacha.json.v1.bak).
- 등급을 미리 알리지 않는다: 장면의 빛기둥·연출의 룬석·카드 테두리는 앞면이 보이기 전까지 같은 보랏빛, 길이·소리도 같다.
- 고르지 않은 룬석은 어두워지지 않는다(고른 것만 커지고 고리·빛).
- 티켓·주문서는 티켓 상인(뽑기 티켓 상점)에서만: 제단의 [티켓 사기] 없음. 티켓 그림은 룬 부적 카드.
- 화면 설정(제단의 [화면 설정], client.json 의 magic*): 글꼴(고딕·명조·바탕·게임 기본), 창 크기, 글자 그림자(기본 끔), 뽑기 연출(보통·짧게·끔), 장면 옆 패널 자리. 제단의 글자는 모두 MagicUi 로 그린다.
- 블록 모습 「별빛 천구」: 남빛 받침·은테·가는 기둥, 푸른 구슬, 금·은 고리 세 겹(입체 띠, ArcaneOrbRenderer.band).
- JEI: RtShopJeiPlugin 이 강화 창·제단 창에서 JEI 목록을 끄고, CinematicGuideMixin 이 RT Shop 메뉴가 열린 장면에서 조합법 안내 책을 끈다.
- 알림(NoticeHud): 화면 위 가운데의 얇은 띠(보스 체력 줄 아래), 오래된 것이 위·새 것이 아래, 한 번에 3개·2줄까지, 왼쪽 점과 테두리가 알림의 빛깔.

3.48 (동행 함께 걷기 · 레이드 잠금 · 보스 음악 · 직업 딱지 · 무기 설명서)
- 동행 NPC 를 여럿이 함께: 같은 NPC 가 40칸 안에 이미 있으면 새로 부르지 않고 그 NPC 와 함께 걷는다(CompanionEntity.guests: 플레이어 → 자기 퀘스트). 퀘스트가 같든 다르든 NPC 가 같으면 하나, 말은 저마다 자기 퀘스트의 대사를 듣는다(Companions.sayTo). 앞장선 사람이 떠나거나 끝내면 남은 사람에게 넘어간다(handOver). NPC 가 다르면 각자 따로. 동행의 처치는 함께 걷는 모두의 퀘스트에 센다.
- 레이드 NPC(안내인·레이드 상인)는 이름 있는 보스를 처음 잡기 전까지 응하지 않는다(RaidConfig.npcsAfterFirstBoss, Raid.npcLocked). 보스별 레이드는 그 보스를 잡아야 열리고, 처치는 보스 ID 별로 적힌다(BossCredit 로 인정된 모두).
- 보스·레이드 음악(BossMusic / BossMusicClient): config/rtshop/boss_music.json 의 tracks(보스 ID → 곡 이름, "*" = 공통 "boss", "" = 무음)와 raid("raid"). 곡은 소리 rtshop:music.<이름>; 파일이 없으면 아무것도 틀지 않는다. 넣기: python3 tools/add_music.py <이름> <파일>. 미리 듣기 /rtshop music play <이름>. 곡이 흐르는 동안 바닐라 음악과 다른 모드의 보스 음악은 끈다(muteOtherBossMusic). 음악은 사용자가 주는 파일만 쓴다(원작 게임 음악 금지).
- 직업 딱지(JobBadge): 가방 창 왼쪽 [직업]. 마우스를 올리면 전투·생활 직업과 패시브(▲ 이점 · ▼ 불리), 누르면 직업 창. JobSyncPacket 이 이름과 설명을 함께 보낸다.
- 무기 설명서(rtshop:weapon_manual, WeaponManuals): Epic Fight 특수기가 있는 무기를 처음 얻으면 한 권(같은 종류·같은 특수기 묶음은 한 권; 기록 rtshop_manuals). 우클릭 → WeaponManualScreen: 종류, 드는 방식별 연속 공격 타수, 달리며·뛰어서 공격, 특수기 이름·설명, 전투 키(지금 설정된 키 이름). 다시 받기 /rtshop manual. 끄기 world_rules.json 의 weaponManuals. 정보는 EfWeapons(리플렉션)로 무기 능력의 표에서 읽는다.
- 행운 상인의 [티켓 사기] 없음: 티켓은 티켓 상인에게서만.

- NPC·동행은 보트·수레에 타지 않는다 (NpcGuard.onMount).
- 스킬북으로 배운 기술은 죽어도 남는다: rules/KeepSkills 가 서버가 켜질 때 Epic Fight 의 게임 규칙 keepSkills 를 켠다 (world_rules.json 의 keepSkillsOnDeath).
- 몹 규칙(rules/MobRules, config/rtshop/mob_rules.json): 모드 몹의 자연 스폰은 20%만 남김(lycanth 10%, hollow=기사·보스·구조물 안·스포너·소환은 그대로). 보스가 아닌 몹은 무기·스킬북·인챈트 물건·모드 아이템을 떨어뜨리지 않는다(RT Shop 아이템, 퀘스트가 건네 달라는 아이템, 몹이 주운 물건, keepItems 는 남김).
- 운영자 기능은 크리에이티브(관전)에서만 (util/Perm): 서바이벌의 OP 는 편집 창·[편집] 단추·OP 전용 명령어를 쓸 수 없다. /gamemode 는 남는다. 코드에서는 hasPermissions(2) 대신 Perm.op(p).
- 마법은 마법사만 (job/MagicLock, world_rules.json 의 magicOnlyForMage): Iron's Spells 의 모든 주문, Spell Engine 의 마법 계열 주문. 근접·활 계열(무기 기술)은 누구나. 크리에이티브는 언제나.

3.50 (스택 유지 · 고급 무기 · 양산 음식 · 가방 창 정리 · 출석 달력)
- 무기를 바꿔도 특수기의 스택·게이지가 남는다 (compat/EfStacks, world_rules.json 의 keepSkillStacks): 기술마다 따로 기억했다가 그 무기를 다시 들면 돌려준다. 죽거나 나가면 지운다.
- 고급 무기(job/WeaponTypes.PREMIUM): 뽑기 표식이 있고 등급이 jobs.json 의 premiumFromGrade(기본 epic) 이상인 무기는 어느 직업의 무기 분류에도 들지 않는다(이점·불리 모두 없음).
- 양산 음식(rules/FoodRules, config/rtshop/food_rules.json): 빵·케이크·쿠키·호박 파이·구운 감자·말린 켈프·날 작물은 배고픔을 절반만 채운다. 목록에 없는 음식(요리사가 조리 도구로 만드는 요리)은 그대로.
- 가방 창 왼쪽 위의 다른 모드 기능 단추(FTB 사이드바)를 없앤다 (client.json 의 hideSidebarButtons). 직업 딱지는 오른쪽 위, 퀘스트 저널 단추 옆.
- 출석 달력: 받은 날(초록)·오늘 받을 날(금빛, 깜빡이는 테)·남은 날(어둡게)·놓친 요일(붉게)을 칸 빛깔로 구분하고 아래에 범례.

3.51 (아이템 규칙 · 대화로 하는 퀘스트 · 뽑기 연출 손질 · 룬 제단 빛 · 토지 뒷정리)
- 아이템 규칙(rules/ItemPolicy, config/rtshop/item_policy.json, 보고서 config/rtshop/export/item_policy.txt). 적는 법: "모드:아이템", "모드:*", * 가 낀 무늬.
  - 상점: shopBan(Arcane Vortex · Nightfall(efn) · 강화 모루), 보스와 얽힌 아이템(bossMods 의 아이템 + 보스가 떨어뜨리는 그 모드의 아이템 + 그것으로만 만드는 물건), 총 모양 무기(gunWords)는 NPC 상점에 오르지 않는다. 플레이어 상점은 제한 없음.
  - 값: priceFactor ("wom:*": 5 = Weapons of Miracles 상점가 5배, 매입가는 그대로).
  - 전리품: lootBan(fruits·artifacts·relics·jewelry·펫·Nightfall·tacz)은 상자·몹·낚시 어디서도 안 나온다. 모드 장비(무기·방어구·도구·장신구)는 보스 전리품에서만. lootAllow(Iron's Spells 잉크)는 그대로 나오고, mobDrops 로 몬스터가 잉크를 조금씩 떨어뜨린다(보스 10배).
  - 조합법: tacz 의 조합법 전부, 지팡이(staffWords · 아이템 갈래), 상점·뽑기에 오른 장비, 모드 장비는 만들 수 없다. 바닐라 장비와 보스 아이템은 그대로 만든다. 팔지 않는 지팡이는 대장장이에게 자동으로 올린다(listStaffs).
  - 셈하는 차례: ShopServer.reload → ItemPolicy.prepare(보스 아이템) → ShopLoader.loadAll(상점 금지·배수) → ItemPolicy.afterShops(오른 장비를 적고 RecipeRules.apply 다시).
- 퀘스트는 대화로(client/QuestTalkScreen): NPC 의 [퀘스트 이야기] → 의뢰 고르기([보고]·[새 의뢰]·[진행 중]) → NPC 의 말(퀘스트 본문이 한 쪽씩) → 대화 상자 위의 의뢰서(목표·보상)를 보며 대답(맡겠습니다 · 일을 마쳤습니다 · 그만두겠습니다, 갈림길 선택지도 대답으로). 결과는 서버가 다시 보낸 목록으로 확인한다(update).
  양피지 창(QuestScreen)은 수첩 전용: /rtshop quest (가방 창의 [퀘스트 수첩] 단추도 같은 명령) — 내용만 보고, 받기·보고는 그 사람에게 가서.
- 무기 분류(직업 편집기): [+ 무기 검색해서 분류하기] — 가방에 없는 무기도 이름으로 찾아 넣는다(PickerScreen.weapons: 무기만/모든 아이템 전환). 종류별 아이템 목록에도 [+ 검색해서 넣기].
- 뽑기 연출: 글자(등급 이름·아이템 이름·YAMATO 제목)를 모두 뺐다(카드 뒷면의 ? 도 마름모 문양으로). 차원참의 작은 둥근 문양 없음. 금빛 벼락은 가지가 뻗는 번개 + 잔벼락 두 번 + 카드 둘레의 전기. 공개 소리: 영웅 = 주문·수정, 전설 = 팡파르·폭죽·종, 야마토 = 음악 + 차원이 열리는 울림.
- 룬 제단: 고른 룬석은 금빛 테가 푸른빛으로(stones_sel.png). 장면에서 룬석·문양·구슬 뒤에 덧그리던 빛무리(Cinematic 의 GLOW, 셰이더·어두운 곳에서 검은 테로 보임)를 없앴고, 구슬은 빛을 받지 않는 그림(RenderType.text)에 하늘빛 가장자리 빛.
- 토지 뒷정리(land/LandSweep, land.json 의 sweepRadius): 토지를 비운 뒤 둘레에서 ① 토지에 걸쳐 잘린 나무를 줄기·잎째 ② 줄기 없는 잎 덩어리 ③ 땅에 닿지 않고 뜬 조각을 치운다. 통나무집(큰 줄기·잎 없음)·땅에 닿은 건물·남의 토지는 건드리지 않는다. 치운 블록은 되돌리기용 백업에 함께 적힌다.
- 점검 손질: 강화 정보 창 점검은 그림이 그려질 때까지 기다림, 짧은 뽑기 연출은 끝까지 간 것도 재생으로 봄 (모드팩 전체에서 화면이 밀릴 때의 헛실패).


## 3.52

- **뽑기 등급**: `gacha.json` 의 `grades` 목록. 기본 등급은 끌 수 있고(지울 수는 없음), 새 등급은 이름·색·연출을 골라 더한다 (최대 12). 마법 뽑기의 확률표는 등급 목록을 따라간다. 클라이언트에는 접속·저장 때 보낸다.
- **귀환권 · 마을 기준 자리**: `rules/TownSpawn` (`town_spawn.json`). `/rtshop spawn set|clear|range <n>`. 처음 들어온 사람의 시작 자리이자 침대 없는 사람의 리스폰 자리. 귀환권은 3초 들고 있기. 고급 귀환권은 하루 구매 수 제한.
- **인사의 once / chance** (`story/Dialogue.greet`): `"once": true` = 그 사람에게 처음 한 번만 (표시: `greeted_<npc>_<글 해시>`), `"chance": 0.2` = 가끔만. 그 창(efn:meen_spear)을 든 사람에게 쓰는 인사에 쓴다. NPC 는 창의 이름을 부르지 않고 "그 창 · 저물녘 빛"으로 가리킨다.
- **읽을 수 있는 물건** (`story/Readables`, `readables.json`, 화면 `client/ReadScreen`): 글은 `tools/gen_readables.py` 가 스토리의 문장을 그대로 옮긴다 (스토리에 없는 문장이면 스크립트가 멈춘다). 쪽마다 need 로 이야기 진행에 맞춰 열린다. 연대기 페이지는 끝낸 퀘스트의 `names` 장면을 모아 보여 준다.


## 3.53

- **기록·주간 순위·칭호** (`rank/Ranks`, `ranks.json`, 저장 `rtshop_ranks`): 종목 kills·bosses·earned·spent·gold·quests·bounties·raids. 수익·소비는 NPC·시스템과의 거래만 센다(`Ranks.earned/spent` 를 부르는 곳만). 처치 인정은 `QuestManager.onKill` 과 같다. 주간 마감 `Ranks.settle` (운영자: `/rtshop rank settle`).
  칭호 효과: mob_damage·boss_damage·sell_bonus·buy_discount·death_keep·quest_gold·bounty_gold·max_health. 효과는 2개까지(종목이 달라야 함), 내거는 칭호 1개(채팅·탭 목록: `PlayerEvent.NameFormat`).
- **전용 NPC 셋** (`quests/npcs.json`): `quest_bounty` 현상금 게시판지기 가렛(하오체) · `quest_ranks` 순위 기록원 테오(해요체) · `quest_titles` 칭호 관리인 아델(합쇼체). 대화 상자 맨 위에 맡은 일이 나오고, 줄 퀘스트가 없으면 [퀘스트]는 보이지 않는다. 소환: `/rtshop npc quest_bounty` 등.
- **조사대 도감** (`story/Codex`, `codex.json`, 저장 `rtshop_codex`, 화면 `client/CodexScreen`): 몹은 모름 → 마주침(가까이에서 눈에 보임) → 잡음. 장비는 지니면 적힌다. Starcatcher 는 뺀다(excludeMods). 보스 설명은 story.json 의 등장 연출 글(intros)에서 온다.
- **조사대 안내서** (`story/Guide`, `guide.json`, 화면 `client/GuideScreen`): 내용은 `tools/gen_guide.py`, 그림은 `tools/gen_guide_images.py` (CI 화면을 줄인 것). 쪽의 `mod` 가 설치되지 않았으면 그 쪽은 보이지 않는다.
- **아이템 쓰임새 설명** (`rules/ItemNotes`, `item_notes.json`, 화면 `client/ItemNoteTips`): Shift 를 누르면 파는 곳·사 주는 곳·강화 재료·뽑기·보스 전리품·퀘스트. 상점을 읽을 때마다 다시 만든다.
- **강화 정보 창**: 연한 금빛 판(`tools/gen_enhance_panel.py`), 전용 글꼴 `assets/rtshop/font/enhance.json` (한글 송명, 숫자·영문 Playfair Display Bold). 글자는 `EnhancePanel.fit` 으로 칸 너비에 맞춰 줄인다. `client.json` 의 `enhanceLuxFont`. 숫자는 높이가 고른 라이닝 모양(`tools/gen_enhance_font.py`). 글꼴의 기준선은 게임 글꼴과 같은 y+7 에 맞춘다: TTF 의 기준선 = 어센트(px) - 3 + shift.
- **아이템 규칙 2판** (`item_policy.json` 의 version 2): Better Nether 도 NPC 상점 금지, 전리품 금지의 `*fruit*:*` → `spmovesets:*`. 예전 파일은 읽을 때 저절로 고쳐 쓴다.
  `shopBannedKeepOwnWays`: 상점 금지 모드(Arcane Vortex·Better Nether·Nightfall)의 장비는 "상점에서만" 규칙에서 빠져 그 모드의 조합법으로 만든다 (Nightfall 은 전리품 금지가 따로 걸려 있다).

## 3.60 (전체 검토에서 고친 것)

- 1장 이글루: 발전과제(좀비 주민 치료) 대신 흔적 「지하실에 갇힌 사람」(c1_felix, 황금 사과 1개, c1_igloo 뒤). 약은 엘레나가 값을 미리 치러 치료소에 남아 있고 금만 가져간다. 여럿이 해도 저마다 할 수 있어야 하는 걸음은 **사람마다 따로 주어지는 것(흔적 · 건네기 · 처치)** 으로 만들 것 — 한 번뿐인 세계의 물건이나 혼자만 받는 발전과제에 걸지 않는다.
- 선택지는 반드시 어딘가에서 받는다 (대화 주제라도). 받지 않는 선택은 두지 않는다: 프로스트모의 옛 선택 삭제, 마녀의 잉크(ch1_witch_*) → 이사벨, 「마중」의 대답(scylla_told / scylla_lantern) → 오스카.
- 없앤 기능을 이야기에서 부르지 않는다: '오늘의 룬'(3.47 삭제) 언급을 「안개가 걷힌 저택」에서 뺌. 거울이 하루에 한 장씩 빛난다는 설정은 그대로.
- 1장에서 로란은 '해독제'를 입에 올리지 않는다 (「시듦과 해독제」의 병영 낙서에서 처음 알게 되므로).
