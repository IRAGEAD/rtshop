# 직접 검토해 주셨으면 하는 시스템 목록 (A-24)

자동 점검은 "동작하는가"만 봅니다. 아래는 사람이 직접 해 보고 **느낌·균형·취향**을 판단해야 하는 것들입니다. 위에서부터 중요합니다.

## 1. 값과 확률 (균형)
- [ ] 상점 가격: 장비·지팡이 값, Weapons of Miracle 5배가 적당한지 (`config/rtshop/item_policy.json` 의 priceFactor)
- [ ] 상점에도 뽑기에도 없는 모드 장비 목록 (`config/rtshop/export/item_policy.txt` 맨 아래) — 쓰게 할 것은 상점에 올리기
- [ ] 뽑기 등급 확률과 조각 값, 마법 뽑기의 실패 확률
- [ ] 강화 확률표와 재료, 보호권 값
- [ ] 칭호 효과의 크기와 열리는 기준 (`ranks.json` 의 titles), 주간 순위 보상 (기본 20,000 / 10,000 / 5,000 G)
- [ ] 현상금 보상, 출석 보상, 레이드·심연 주간 보상
- [ ] 잉크 드랍 확률 (item_policy.json 의 mobDrops)

## 2. 직접 해 봐야 아는 것 (연출·조작)
- [ ] 뽑기 연출 (영웅·전설·야마토): 길이, 소리 크기, 셰이더를 켠 화면
- [ ] 강화 연출 (+7 이상 세 장면), 강화 정보 창의 새 글꼴과 금빛 판
- [ ] 룬 제단 장면: 고른 룬석의 푸른빛, 셰이더에서의 모습
- [ ] 퀘스트 대화 형식: 수락·완료·포기의 흐름이 자연스러운지
- [ ] 보스 등장 연출과 기억의 문 입장
- [ ] 귀환권 3초 대기, 마을 기준 자리(`/rtshop spawn set` 으로 먼저 정해야 함)

## 3. 글 (말투·내용)
- [ ] 새 NPC 셋의 말투: 가렛(하오체), 테오(해요체), 아델(합쇼체)
- [ ] 그 창(Duskfire)을 들었을 때의 인사와 "그 창에 대하여" 대화
- [ ] 서약서·연대기 페이지·일지·지도·항해일지를 펼쳤을 때의 글
- [ ] 조사대 안내서(가이드북)의 내용 — 틀린 설명, 빠진 시스템 (`config/rtshop/guide.json` 에서 고칠 수 있음)
- [ ] 칭호 이름

## 4. 서버를 열기 전에 운영자가 정해야 하는 것
- [ ] 마을 기준 자리: `/rtshop spawn set`
- [ ] 새 NPC 세우기: `/rtshop npc quest_bounty`, `/rtshop npc quest_ranks`, `/rtshop npc quest_titles`
- [ ] NPC 배치와 건물 (A-9)
- [ ] PvP 구역, 레이드 구역과 돌아올 자리
- [ ] 강화 모루를 놓을 자리 (마을에 하나)

## 5. 모드팩 전체에서 볼 것
- [ ] 도감에 나오면 안 되는 몹이 있는지 (`codex.json` 의 hideMobs), 빠진 몹이 있는지 (extraMobs)
- [ ] 다른 모드의 화면·HUD 와 겹치는 표시가 없는지 (`/rtshop hud` 로 옮길 수 있음)
- [ ] 리소스팩·셰이더를 켠 상태에서 글꼴이 깨지지 않는지
